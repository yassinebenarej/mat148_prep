Big idea

A set is a collection of objects (its elements); a small toolkit of symbols lets us say precisely how elements and sets relate and how to build new sets.

Definitions

  • Set: a "collection of things" called elements (informal, but enough for this course).
  • Subset: A ⊆ B when every element of A is also an element of B.
  • Union: A ∪ B = everything in at least one of A, B.
  • Intersection: A ∩ B = everything in both A and B.
  • Empty set ∅: the set with no elements.

Notation & conventions

  • Curly braces { } mark where a set's description starts and ends; a set can be given by a description ({even integers}) or by listing its elements ({4, 5, 6}).
  • x ∈ A: "x is an element of A"; x ∉ A: "x is not an element of A".
  • ⚠ Subset notation isn't universal: some books use ⊆ for "subset, may be equal" and ⊂ for "proper subset"; others use ⊂ for "may be equal". The safest choice is ⊆ (may be equal) and ⊊ (strict). Always agree on the convention.
  • Standard number sets: ℕ = {0, 1, 2, 3, …} (natural numbers; this course starts at 0, some books start at 1), ℤ = integers {…, −2, −1, 0, 1, 2, …}, ℚ = rationals (quotients of integers), ℝ = reals (any number with a decimal expansion).

Theorems / facts

  • ℕ ⊆ ℤ ⊆ ℚ ⊆ ℝ.
  • Example: B = {4, 5, 6}, C = {2, 4}, D = {4, 5}: 4 ∈ B, 2 ∉ B, D ⊆ B, C ∪ D = {2, 4, 5}, C ∩ D = {4}.

Pitfalls & warnings

  • Whether 0 ∈ ℕ is a convention, not a fact — check which one is in use.
  • ∈ relates an element to a set; ⊆ relates two sets. Don't mix them.

Exam-ready checklist

  • Read and write ∈, ∉, ⊆, ∪, ∩, ∅ correctly.
  • Compute unions and intersections of explicit sets.
  • Know ℕ, ℤ, ℚ, ℝ and how they nest.

Big idea

Set-builder notation describes a set precisely by a rule, even when its elements can't be listed. Intervals are the most important family of sets built this way.

Definitions

  • Intervals (a, b ∈ ℝ):
    • [a, b] = {x ∈ ℝ : a ≤ x ≤ b} (closed: both endpoints included)
    • (a, b) = {x ∈ ℝ : a < x < b} (open: no endpoints)
    • [a, b) = {x ∈ ℝ : a ≤ x < b}, and similarly (a, b]
    • (a, ∞) = {x ∈ ℝ : x > a}, [a, ∞), (−∞, b), (−∞, b]

Notation & conventions

  • Two equivalent forms: A = {x ∈ ℤ : x² < 6} = {x ∈ ℤ | x² < 6}. The ":" or "|" is read "such that", and should only be used inside set-builder notation.
  • Form 1, filter: {where the elements come from : extra constraints}. Example: {x ∈ ℤ : x² < 6} = {−2, −1, 0, 1, 2}.
  • Form 2, image: {shape of the elements : explanation of the variables}. Example: with A as above, B = {2x : x ∈ A} = {−4, −2, 0, 2, 4}.
  • Intervals: square bracket = endpoint included (filled dot), round bracket = endpoint excluded (open dot).
  • ∞ is not a number. It is never included, so it always gets a round bracket.
  • [a, b] is the name of a set, defined by the set-builder description.

Theorems / facts

  • Exercises from the video (worth redoing): {x ∈ ℤ : x ≥ 0} = ℕ; {y ∈ ℕ | y² < 6} = {0, 1, 2}; {n² + 1 | n ∈ B, n even} where B is the previous set gives {1, 5}; {x ∈ ℝ | x² < 0} = ∅.

Methods & proof templates

  • To decode a set-builder description: identify the source set (left), apply the constraint (right), then list the result if you can.

Pitfalls & warnings

  • Don't use ":" or "|" for "such that" outside set-builder notation.
  • Never write a bracket on ∞, as in "[a, ∞]".

Exam-ready checklist

  • Read and write both forms of set-builder notation.
  • Convert between set-builder descriptions and explicit lists.
  • Write every interval type in set-builder form and draw it on a number line.

Big idea

∀ ("for all / for every") and ∃ ("there exists / there is") turn a predicate about x into a true-or-false statement. Without a quantifier, or a previously fixed value, a formula with a free variable is meaningless.

Definitions

  • ∀x ∈ A, P(x): every element of A satisfies P.
  • ∃x ∈ A such that P(x): at least one element of A satisfies P.

Notation & conventions

  • In math, "there exists / there is / has a solution" always means at least one, never "exactly one". If you mean exactly one, say so.
  • "Such that" (s.t.) after ∃ adds nothing mathematically, but makes the sentence grammatical and easier to read. Logicians write a comma instead.
  • A bare formula like "x² = 5" is a predicate, not a statement: it is neither true nor false until x is quantified or fixed.

Theorems / facts

  • ∀x ∈ ℝ, x² ≥ 0: TRUE.
  • ∀x ∈ ℤ, x > π: FALSE. The counterexample x = 1 is enough.
  • ∃x ∈ ℝ s.t. x² = 5: TRUE (e.g. x = −√5). One example is enough.
  • ∃x ∈ ℝ s.t. x² = −1: FALSE.

Methods & proof templates

  • To prove ∀: show it for every element. To disprove ∀: give one counterexample.
  • To prove ∃: exhibit one example. To disprove ∃: show that no element works.

Pitfalls & warnings

  • Never start a definition, theorem or proof with an unquantified formula (like "x² = 5") whose variable hasn't been fixed. It's meaningless, which is worse than false.

Exam-ready checklist

  • Translate between ∀/∃ symbols and English.
  • Decide the truth of simple quantified statements and justify it with an example or counterexample.
  • Recognize when a variable is free and the statement is therefore meaningless.

Big idea

With two or more quantifiers, the order matters: it records what depends on what. A variable introduced later may depend on the variables introduced before it.

Theorems / facts

  • (1) ∀x ∈ ℤ, ∃y ∈ ℤ s.t. x < y. TRUE: "every integer is smaller than some integer". y may be different for different x (e.g. y = x + 1).
  • (2) ∃y ∈ ℤ s.t. ∀x ∈ ℤ, x < y. FALSE: "some integer is greater than all integers". The same y would have to work for every x.

Notation & conventions

  • In "∀x ∃y", y is allowed to depend on x. In "∃y ∀x", y is chosen first and must be the same for all x.

Methods & proof templates

  • To read a multi-quantifier statement, go left to right and ask, for each ∃: "may this choice depend on the variables quantified before it?"

Pitfalls & warnings

  • Swapping ∀ and ∃ usually changes the meaning completely. This becomes crucial in the ε–δ definition of a limit, where δ depends on ε.

Exam-ready checklist

  • Explain in words the difference between ∀x∃y and ∃y∀x.
  • Decide the truth of double-quantified statements, with a justification.
  • Turn an English sentence into the correctly ordered symbolic form, and back.

Big idea

Proofs of quantified statements follow fixed templates. ∀ means: fix an arbitrary element. ∃ means: choose a witness, then verify it. To disprove a statement, prove its negation.

Definitions

  • Negation of a statement S: the statement that is true exactly when S is false.
  • The negation of "∀x ∈ ℤ, x > 0" is "∃x ∈ ℤ s.t. x ≤ 0".

Notation & conventions

  • "Let x ∈ ℤ" in a proof means "I fix an arbitrary x ∈ ℤ". Arbitrary: you don't get to choose it, so the proof must work for every x. Fix: from now on x has a specific (unknown) value you can work with.
  • ■ (filled square) or □ marks the end of a proof.

Theorems / facts

  • Thm 1: A = {2, 3, 4}, ∀x ∈ A, x > 0. Proof: check each element (2 > 0, 3 > 0, 4 > 0). ■
  • Thm 2: "∀x ∈ ℤ, x > 0" is FALSE. Prove the negation "∃x ∈ ℤ, x ≤ 0": take x = −6, which is in ℤ and ≤ 0. ■
  • Thm 3: ∀x ∈ ℤ, ∃y ∈ ℤ s.t. x < y. Proof: Let x ∈ ℤ. Take y = x + 1. Then y ∈ ℤ ✓ and y > x ✓. ■

Methods & proof templates

  • Prove ∀x ∈ A, P(x): for a finite A, check every element. In general, write "Let x ∈ A" (fix an arbitrary one) and prove P(x).
  • Prove ∃x s.t. P(x): "Take x = …" (choose a witness), then verify that it belongs to the set and satisfies P.
  • Prove ∀x ∃y P(x, y): (1) fix an arbitrary x, (2) choose y in terms of x, (3) verify the conditions. This template generalizes directly to ε–δ proofs.
  • Disprove S: prove ¬S.

Pitfalls & warnings

  • You can only operate with a variable once it has been fixed. In the theorem statement, x is a quantified variable with no meaning of its own, so "take y = x + 1" only makes sense after "Let x ∈ ℤ".
  • Skipping the order (fix → choose → verify) leads to bad proofs, or to "proofs" of false claims.

Exam-ready checklist

  • Write proofs of ∀, ∃ and ∀∃ statements with the correct template.
  • Negate a simple quantified statement.
  • Disprove a ∀-statement with an explicit counterexample.

Big idea

Any "for every x ∈ ∅, …" statement is (vacuously) true, and any "there exists x ∈ ∅ such that …" statement is false, no matter what the condition says.

Theorems / facts

  • ∀x ∈ ∅, x > 0: TRUE.
  • ∃x ∈ ∅ s.t. x > 0: FALSE.
  • More generally: ∀x ∈ ∅, (anything) is true; ∃x ∈ ∅ s.t. (anything) is false.

Methods & proof templates

  • To prove "∀x ∈ S, P(x)" true: check all elements of S. If S has 0 elements, there is nothing to check, so you're done.
  • To prove it false: find one element of S that fails P. In ∅ there is no element to find, so it can't be false.

Pitfalls & warnings

  • Don't reason "it's true only because I can't disprove it". Both views agree: you can prove it (nothing to check) and you can't disprove it (no counterexample exists).

Exam-ready checklist

  • Decide the truth of quantified statements over ∅ and explain why.
  • Apply the same reasoning to definitions that might be vacuously satisfied (e.g. a condition on an empty set of points).

Big idea

"If P, then Q" (P ⇒ Q) only promises that Q holds whenever P holds; when P is false it says nothing. It is equivalent to its contrapositive (not Q ⇒ not P), but not to its converse or inverse.

Definitions

  • P ⇒ Q ("if P then Q", "P implies Q"): whenever P is true, Q is true. When P is false, we don't care.
  • Contrapositive: not Q ⇒ not P, which is equivalent to P ⇒ Q.
  • P ⇐ Q: Q ⇒ P (the arrow points at the conclusion).
  • P ⇔ Q ("P if and only if Q", written "iff"): P ⇒ Q and Q ⇒ P. Equivalently, P and Q are equivalent: both true or both false.

Notation & conventions

  • "If P then Q", "P ⇒ Q" and "P implies Q" are interchangeable.
  • "iff" is written but spoken as "if and only if".
  • Everyday English blurs "if" and "iff". In math they are strictly different.

Theorems / facts

  • For x ∈ ℝ: x > 10 ⇒ x > 6 is TRUE. With x = 12: T ⇒ T. With x = 8: F ⇒ T. With x = 3: F ⇒ F. All are consistent with the implication.
  • If A ⊆ ℝ and we know x ∈ A ⇒ x > 0: from x ∉ A, no conclusion. From x > 0, no conclusion. From x ≤ 0, we get x ∉ A (contrapositive).
  • n is even ⇐ n is a multiple of 4 (the converse is false: 6 is even but not a multiple of 4).
  • n is even ⇔ n + 1 is odd.
  • "0 > 1 ⇒ 103574289 is prime" is TRUE: a false hypothesis makes the implication true, whatever the conclusion.

Methods & proof templates

  • To prove P ⇒ Q: assume P, then deduce Q. Equivalently, assume not Q and deduce not P.
  • To prove P ⇔ Q: prove both directions.

Pitfalls & warnings

  • From P ⇒ Q you CANNOT conclude not P ⇒ not Q, nor Q ⇒ P.
  • An implication with a false hypothesis is true ("vacuously true").

Exam-ready checklist

  • Determine the truth of implications, including ones with a false hypothesis.
  • Form the contrapositive and know that it is equivalent to the original.
  • Distinguish ⇒, ⇐ and ⇔, and know what proving an iff requires.

Big idea

The negation of an "if P, then Q" is never another if-then. It says that the one forbidden case happens: P is true and Q is false. Many conditionals also carry a hidden "for all", and the negation must write that quantifier out.

Definitions

  • "If P then Q" (P ⇒ Q): whenever P is true, Q must also be true. When P is false, nothing is required.
  • Negation: ¬(P ⇒ Q) ⟺ (P and ¬Q).

Notation & conventions

  • Hidden quantifier: with A ⊆ ℝ, the sentence "If x ∈ A, then x > 0" really means (∀x ∈ ℝ)(x ∈ A ⇒ x > 0). The "for all" is understood but not written.
  • "s.t." means "such that".

Theorems / facts

  • A conditional P ⇒ Q allows three of the four truth cases: (P, Q), (¬P, Q), (¬P, ¬Q). Only the fourth case, (P and ¬Q), is ruled out.
  • ∀x (P(x) ⇒ Q(x)) means every x is in one of the three allowed cases.
  • ¬[∀x (P(x) ⇒ Q(x))] ⟺ ∃x (P(x) and ¬Q(x)).

Methods & proof templates

Worked example. Let A ⊆ ℝ and (✱) "If x ∈ A, then x > 0".

  1. Write the hidden quantifier: ∀x ∈ ℝ, (x ∈ A ⇒ x > 0).
  2. Spell out what it means: every x ∈ ℝ satisfies (x ∈ A and x > 0) OR (x ∉ A and x > 0) OR (x ∉ A and x ≤ 0).
  3. Negate: at least one real x is in none of those cases. That x must be in the fourth case.
  4. Negation of (✱): ∃x ∈ ℝ s.t. (x ∈ A and x ≤ 0).

General recipe: to negate ∀x, P(x) ⇒ Q(x), change ∀ to ∃ and replace the implication with "P(x) and not Q(x)".

Pitfalls & warnings

  • Do NOT write the negation as another if-then. "If x ∈ A then x ≤ 0" and "If x ∉ A then x ≤ 0" are both wrong.
  • Do not forget the hidden quantifier. The negation MUST state ∃ explicitly.
  • The negation of x > 0 is x ≤ 0, not x < 0.

Exam-ready checklist

  • Find and write out the hidden ∀ in a conditional statement.
  • List the three allowed cases of P ⇒ Q and the one forbidden case.
  • Negate ∀x (P(x) ⇒ Q(x)) as ∃x (P(x) ∧ ¬Q(x)).
  • Spot a wrong negation that has been written as an if-then.

Big idea

The lecturer takes a typical student "proof" of √(xy) ≤ (x+y)/2 and shows it is not a proof. It assumes what it wants to prove, never says what x and y are, and gives no explanation. The correct proof starts from known facts and ends at the claim. Working backwards from the claim is allowed only as "rough work" for finding the idea.

Definitions

  • Rough work: scratch work where you start from the claim and manipulate it to see where it could come from. It is a way to find a proof, not a proof itself.

Notation & conventions

  • A theorem is never just an equation or inequality. It must say when the claim holds, e.g. "Let x, y ≥ 0. Then …".
  • Write words that explain the steps, such as "Since a square is always non-negative…" or "Since both sides are non-negative…".
  • Plain reversible algebra (expanding, multiplying by a positive constant, adding to both sides) can go without comment.
  • √(a²) = |a|, not a.
  • ∎ marks the end of a proof.

Theorems / facts

  • Theorem (AM–GM for two numbers). Let x, y ≥ 0. Then √(xy) ≤ (x+y)/2.
  • Without the hypothesis the inequality is false. For x = y = −1: LHS = √1 = 1 and RHS = −1, and 1 ≤ −1 is false.
  • You can take square roots of both sides of an inequality only when both sides are ≥ 0.

Methods & proof templates

The bad "proof" (it starts from the claim and works forward): xy ≤ ((x+y)/2)² → xy ≤ (x²+2xy+y²)/4 → 4xy ≤ x²+2xy+y² → 0 ≤ x²−2xy+y² = (x−y)², "true, done." This only shows: IF the claim holds, THEN (x−y)² ≥ 0. That says nothing about whether the claim is true.

The correct proof (the same steps in reverse):

  1. Since a square is always non-negative: 0 ≤ (x−y)² = x² − 2xy + y².
  2. Add 4xy to both sides: 4xy ≤ x² + 2xy + y².
  3. Divide by 4: xy ≤ (x² + 2xy + y²)/4 = ((x+y)/2)².
  4. Both sides are non-negative, so take square roots: √(xy) ≤ √(((x+y)/2)²) = |(x+y)/2|.
  5. Since x, y ≥ 0, |(x+y)/2| = (x+y)/2. This is the step where the hypothesis is used. ∎

Workflow: (1) Do rough work backwards from the claim. (2) Find a true starting fact. (3) Write the proof forwards and check that each step is valid in that direction. (4) Expect to use every hypothesis somewhere.

Pitfalls & warnings

  • Never begin by assuming what you want to prove. Working forward from the claim to something true proves nothing unless every step is reversible and you actually reverse them.
  • Thinking "these are all equivalent" is not the same as writing it. What is on the page is what counts.
  • If a proof works equally well for a false statement, it is useless. If you never used the hypothesis (here x, y ≥ 0), something is wrong.
  • Proofs that are only algebra with no words are usually not acceptable.
  • √(a²) ≠ a in general. It equals |a|.

Exam-ready checklist

  • State a theorem with all its hypotheses ("Let … Then …").
  • Tell rough work apart from a proof, and turn backwards rough work into a forward proof.
  • Prove √(xy) ≤ (x+y)/2 for x, y ≥ 0, and point out where x, y ≥ 0 is used.
  • Use a counterexample to show why a hypothesis is needed.
  • Justify steps such as taking square roots (both sides ≥ 0) and √(a²) = |a|.

Big idea

The lecturer builds a precise definition of "increasing function" step by step. Each piece is needed: naming the objects, the domain ("increasing on I"), the quantifier ∀, and the conditional ⇒. Without any one of them the statement means something else or nothing at all.

Definitions

  • Increasing on an interval. A function f is increasing on an interval I when ∀x₁, x₂ ∈ I, x₁ < x₂ ⇒ f(x₁) < f(x₂).

Notation & conventions

  • The concept being defined is "increasing on I", not just "increasing". A function can be increasing on one interval and not on another.
  • Every symbol in a definition must be introduced: what f is, what I is, where x₁ and x₂ live.
  • "When" in a definition means "by definition, exactly when".

Theorems / facts

  • "f′ > 0" is NOT the definition of increasing. It is related, but a function with a corner (e.g. two line segments with different positive slopes) is increasing yet has no derivative at the corner. The derivative-based definition would wrongly exclude it.
  • A good definition includes exactly the objects you intend and nothing else.

Methods & proof templates

How the definition is built (each draft and why it fails):

  1. "f always goes up." This is intuition, not a definition.
  2. "f′ > 0." Rejected because of the corner counterexample.
  3. "x₁ < x₂, f(x₁) < f(x₂)." Nothing has been introduced, so there is no context.
  4. "f is increasing on I when, for x₁, x₂ ∈ I: x₁ < x₂, f(x₁) < f(x₂)." Meaningless, since it does not say for which x₁, x₂.
  5. "∀x₁, x₂ ∈ I, x₁ < x₂ AND f(x₁) < f(x₂)." Precise but wrong. It claims every pair has x₁ < x₂, which is never true.
  6. "∀x₁, x₂ ∈ I, x₁ < x₂ ⇒ f(x₁) < f(x₂)." Correct.

Pitfalls & warnings

  • Do not use "positive derivative" as the definition of increasing.
  • If you leave out the quantifier, the statement has no meaning.
  • Writing "and" where you need "⇒" changes the meaning completely.
  • Leaving out the domain is a mistake. Write "increasing on I".

Exam-ready checklist

  • State the definition of "f is increasing on I" exactly, with ∀ and ⇒.
  • Explain why f′ > 0 is not the definition, using the corner example.
  • Explain what goes wrong if you drop the quantifier, use "and" instead of "⇒", or omit the interval.
  • Apply the same care (introduce notation, quantifiers, conditional) to write other definitions.

Big idea

To prove that a specific example satisfies a definition, write the definition out. Its logical form (∀ then ⇒) tells you how the proof must be structured, so no memorized template is needed. The example used is f(x) = 3x + 7, which is increasing on ℝ.

Definitions

  • f is increasing on I ⟺ ∀x₁, x₂ ∈ I, x₁ < x₂ ⇒ f(x₁) < f(x₂).

Notation & conventions

  • WTS = "want to show". Use it to mark a statement as your goal, not as something you are claiming is already true.
  • "Let x₁, x₂ ∈ ℝ." fixes arbitrary, generic values that you do not choose. Because they are arbitrary, the argument covers every pair.
  • "Assume …" introduces the if-part of an implication.
  • Finish by stating what you have shown, e.g. "I've shown f(x₁) < f(x₂)."

Theorems / facts

  • f(x) = 3x + 7 is increasing on ℝ.

Methods & proof templates

Template for proving ∀x ∈ S, P(x) ⇒ Q(x):

  1. WTS: ∀x ∈ S, P(x) ⇒ Q(x).
  2. Let x ∈ S (arbitrary).
  3. Assume P(x).
  4. … (argument) …
  5. Therefore Q(x). ∎

Worked example: WTS ∀x₁, x₂ ∈ ℝ, x₁ < x₂ ⇒ f(x₁) < f(x₂).

  • Let x₁, x₂ ∈ ℝ. Assume x₁ < x₂.
  • Multiply by 3 > 0: 3x₁ < 3x₂. Add 7: 3x₁ + 7 < 3x₂ + 7.
  • That is f(x₁) < f(x₂). ∎

Pitfalls & warnings

  • Do not write the goal as if it were a known fact. Label it WTS or "I want to prove".
  • Do not pick specific numbers when the claim is "for all". Fix generic values with "Let".
  • To prove an implication, assume the if-part and derive the then-part. Never assume the conclusion.

Exam-ready checklist

  • Write the definition you need, and read the proof structure from it.
  • Use "Let … Assume … WTS … Therefore …" correctly for a ∀ followed by ⇒.
  • Prove from the definition that a linear function with positive slope is increasing.

Big idea

To prove that something does NOT satisfy a definition, negate the definition first. Then prove the negated statement. In this case it is an existence statement, so one explicit example is enough. The example is g(x) = cos x, which is not increasing on [0, π].

Definitions

  • g is not increasing on I ⟺ ¬[∀x₁, x₂ ∈ I, x₁ < x₂ ⇒ g(x₁) < g(x₂)] ⟺ ∃x₁, x₂ ∈ I s.t. ¬(x₁ < x₂ ⇒ g(x₁) < g(x₂)) ⟺ ∃x₁, x₂ ∈ I s.t. (x₁ < x₂ and g(x₁) ≥ g(x₂)).

Notation & conventions

  • WTS marks the goal. "s.t." means "such that".
  • "Take x₁ = …, x₂ = …" is how you prove an existence claim: name the witnesses, then check the conditions.
  • You may negate in one step or in several steps. Either is fine.

Theorems / facts

  • cos is not increasing on [0, π].
  • ¬(∀ …) = ∃ ¬(…). ¬(P ⇒ Q) = P ∧ ¬Q (see video 1.8). ¬(a < b) is a ≥ b.

Methods & proof templates

Template for proving ∃x s.t. P(x): name a specific x, then verify P(x).

Worked example: WTS ∃x₁, x₂ ∈ [0, π] s.t. (x₁ < x₂ and g(x₁) ≥ g(x₂)).

  • Proof: Take x₁ = 0 and x₂ = π/2. Both are in [0, π].
  • 0 < π/2 ✓.
  • g(0) = cos 0 = 1 ≥ 0 = cos(π/2) = g(π/2) ✓. ∎
  • A sketch of the graph helps choose the pair, and almost any pair works.

Pitfalls & warnings

  • The negation of "f(x₁) < f(x₂)" is "f(x₁) ≥ f(x₂)", not ">".
  • The negation of the implication is "and", not another implication.
  • For an ∃ statement you do not fix arbitrary values. You choose specific ones.

Exam-ready checklist

  • Negate the definition of "increasing on I" correctly in one go.
  • Prove an existence statement by giving explicit witnesses and checking every condition, including membership in I.
  • Show that a given function is not increasing on a given interval.

Big idea

Before proving a theorem, rewrite it formally with set-up, hypothesis and conclusion. Then use the hypothesis freely (assume it) and prove the conclusion, following the structure of its definition. The example: the sum of increasing functions is increasing.

Definitions

  • f is increasing on I ⟺ ∀x₁, x₂ ∈ I, x₁ < x₂ ⇒ f(x₁) < f(x₂).

Notation & conventions

  • Parts of a theorem:
    • Set-up: introduces notation, e.g. "Let f, g be functions on an interval I. Let h = f + g."
    • Hypothesis (the IF part): you may assume it. You do not prove it.
    • Conclusion (the THEN part): what you must prove.
  • Most theorems are if-then statements, though often not written that way.
  • Always mark your goal: "WTS", "My objective is", "I am trying to prove". Your reader cannot read your mind. Without the label, it looks as if you are starting from the conclusion.

Theorems / facts

  • Theorem. Let f, g be functions on an interval I and h = f + g. IF f and g are increasing on I, THEN h is increasing on I.

Methods & proof templates

Proof:

Big idea

Induction proves a statement Sₙ for every natural number n ≥ n₀ in two steps. First prove the base case S_{n₀}. Then prove the implication Sₙ ⇒ Sₙ₊₁ for every n ≥ n₀. Together they give S_{n₀}, S_{n₀+1}, … like a chain. The worked example is n! > 2ⁿ for all n ≥ 4.

Definitions

  • Proof by induction (of ∀n ≥ n₀, Sₙ):
    1. Base case: prove S_{n₀}.
    2. Induction step: prove ∀n ≥ n₀, Sₙ ⇒ Sₙ₊₁.
    3. Conclusion: Sₙ holds for all n ≥ n₀. (S₄ is true, and S₄ ⇒ S₅ ⇒ S₆ ⇒ …)
  • Induction hypothesis: the assumption Sₙ made inside the induction step.

Notation & conventions

  • Give the statement a name, such as Sₙ, so you can refer to it.
  • Say explicitly that you are using induction, e.g. "Pf (by induction on n)". The reader cannot read your mind.
  • In the induction step: "Let n ≥ n₀" (fix an arbitrary n), then "Assume Sₙ. WTS Sₙ₊₁."
  • Point out where you use the induction hypothesis, e.g. "by induction hypothesis".

Theorems / facts

  • Theorem. ∀n ≥ 4, n! > 2ⁿ.
  • The induction step alone proves nothing about whether any Sₙ is true. All the Sₙ could be false and the implications would still hold. You need both steps.

Methods & proof templates

Template:

  • Pf (by induction on n).
  • Base case (n = n₀): WTS S_{n₀}. [check it]
  • Induction step: Let n ≥ n₀. Assume Sₙ. WTS Sₙ₊₁. [argument using Sₙ] ∎

Worked example: n! > 2ⁿ for n ≥ 4.

  • Base case (n = 4): WTS 4! > 2⁴. 4! = 24 and 2⁴ = 16 ✓.
  • Induction step: Let n ≥ 4. Assume n! > 2ⁿ. WTS (n+1)! > 2ⁿ⁺¹.
    • (n+1)! = (n+1)·n! > (n+1)·2ⁿ, by the induction hypothesis, multiplying by n+1 > 0.
    • (n+1)·2ⁿ > 2·2ⁿ = 2ⁿ⁺¹, because n ≥ 4 gives n + 1 > 2.
    • So (n+1)! > 2ⁿ⁺¹. ∎
  • Useful identities: (n+1)! = (n+1)·n! and 2ⁿ⁺¹ = 2·2ⁿ. They link the n+1 case to the n case.

Pitfalls & warnings

  • Common misunderstanding: the induction step does NOT prove Sₙ₊₁, and it does not prove Sₙ. It proves only the implication Sₙ ⇒ Sₙ₊₁ for a fixed but arbitrary n.
  • Fix n before assuming anything ("Let n ≥ 4"). Otherwise nothing makes sense.
  • The base case is the smallest n in the statement (here 4), not necessarily 0 or 1.
  • Do not forget the base case.

Exam-ready checklist

  • State the two parts of an induction proof and explain why they imply ∀n ≥ n₀, Sₙ.
  • Write the induction step with "Let n ≥ n₀. Assume Sₙ. WTS Sₙ₊₁." and mark where the induction hypothesis is used.
  • Prove n! > 2ⁿ for n ≥ 4.
  • Explain why proving only the induction step is not enough.

Big idea

The formula 1 + 2 + … + n = n(n+1)/2 can be proved in two equally valid ways. One is a direct proof by pairing the terms (the Gauss trick). The other is a proof by induction. Statements that depend on n are natural candidates for induction, but a direct proof may also exist. Which one to use is a matter of taste.

Definitions

  • Sₙ = 1 + 2 + 3 + … + n, the sum of the first n positive integers.

Notation & conventions

  • Label each proof clearly, e.g. "Proof #1" and "Proof #2 (By induction on n)". Always announce induction.
  • A direct proof handles all n at once: "Let n ≥ 1", then algebra, with no assumptions.

Theorems / facts

  • Theorem. ∀n ≥ 1, 1 + 2 + 3 + … + n = n(n+1)/2.

Methods & proof templates

Proof #1 (direct). Let n ≥ 1.

  • Write Sₙ = 1 + 2 + 3 + … + n.
  • Write it in reverse: Sₙ = n + (n−1) + (n−2) + … + 1.
  • Add the two lines term by term. Each pair sums to n + 1 (1 + n, 2 + (n−1), 3 + (n−2), …), and there are n pairs.
  • So 2Sₙ = n(n+1), and Sₙ = n(n+1)/2. ∎

Proof #2 (by induction on n).

  • Base case (n = 1): WTS 1 = 1(1+1)/2 ✓.
  • Induction step: Let n ≥ 1. Assume 1 + 2 + … + n = n(n+1)/2. WTS 1 + 2 + … + (n+1) = (n+1)(n+2)/2.
    • 1 + 2 + … + (n+1) = [1 + 2 + … + n] + (n+1). The new sum is the old sum plus one more term.
    • = n(n+1)/2 + (n+1), by the induction hypothesis.
    • = [n(n+1) + 2(n+1)]/2 = (n+1)(n+2)/2. ∎

Pitfalls & warnings

  • In the induction step, the WTS is the formula with n replaced by n+1 on both sides: (n+1)(n+2)/2, not n(n+1)/2 + 1.
  • Remember that the induction proof proves the formula only for n = 1, plus the implications "true for n ⇒ true for n+1". Together these give all n.
  • Do not assume induction is the only option. Look for a direct argument too.

Exam-ready checklist

  • Prove 1 + 2 + … + n = n(n+1)/2 directly with the reverse-and-add trick.
  • Prove the same formula by induction, with the base case, the induction hypothesis and the algebra.
  • In an induction step for a sum, split off the last term so you can use the induction hypothesis.
  • Decide whether a statement about n suits a direct proof or an induction proof.

Big idea

Sometimes a function is undefined at a point only "by accident": its graph is a nice curve with one point missing (a hole). The limit is the value the function "should" have there, the value that nearby points suggest. This video gives the intuition only. The formal definition comes in 2.5.

Definitions

  • Intuitive idea (not a definition yet): lim_{x→a} f(x) = L means "if x is very close to a but x ≠ a, then f(x) is very close to L."

Notation & conventions

  • lim_{x→a} f(x) = L, read "the limit as x approaches a of f(x) is L."
  • When you cancel a factor, give the original function and the simplified one different names (f and g). They agree everywhere except at the point where you divided by zero.
  • In graphs, an open circle marks a hole (a missing point).

Theorems / facts

  • If f(x) = g(x) for all x ≠ a, and g is "nice" at a, then the limit of f at a is g(a). Whether f(a) is defined does not matter. (Stated informally here.)

Methods & proof templates

Example 1: f(x) = (x² − 1)/(x − 1). Domain ℝ∖{1}, so f(1) is undefined.

  • Factor: (x−1)(x+1)/(x−1) = x + 1, valid only when x ≠ 1.
  • Let g(x) = x + 1. Then f = g except at 1, where g(1) = 2 and f(1) is undefined.
  • The graph of f is the line y = x + 1 with a hole at (1, 2), so lim_{x→1} f(x) = 2.

Example 2: f(x) = (1 − √(1+x))/x. Domain [−1, 0) ∪ (0, ∞), so f(0) is undefined.

  • Numerical approach: f(1) ≈ −0.4142, f(0.1) ≈ −0.4881, f(0.01) ≈ −0.4988, f(0.001) ≈ −0.49988, f(0.000001) ≈ −0.4999999. The values suggest −1/2.
  • Algebraic approach: multiply top and bottom by the conjugate 1 + √(1+x): (1 − (1+x)) / (x[1+√(1+x)]) = −x / (x[1+√(1+x)]) = −1/(1+√(1+x)), valid when x ≠ 0.
  • g(x) = −1/(1+√(1+x)) is smooth near 0, and g(0) = −1/2. So lim_{x→0} f(x) = −1/2.

Pitfalls & warnings

  • Cancelling a factor such as (x−1) or x is only valid where that factor is nonzero. The simplified function is a different function, because it is defined at the point and the original is not.
  • A table of values only suggests a limit (it is a guess). It does not prove anything.
  • The intuitive "very close" idea is not a definition.

Exam-ready checklist

  • State the intuitive meaning of lim_{x→a} f(x) = L, including the "x ≠ a" part.
  • Find the domain of a rational or root function and spot where it is undefined.
  • Remove a 0/0 problem by factoring, or by multiplying by the conjugate, and note the "valid when x ≠ a" restriction.
  • Sketch the graph of a function that has a removable hole.
  • Explain why the value f(a), or whether f(a) exists, does not affect the limit.

Big idea

A limit exists only if f(x) approaches one single real number as x → a (with x ≠ a). Two ways this can fail: the function oscillates wildly, or it grows without bound. In the second case we write "= ∞", even though the limit does not exist.

Definitions

  • Recall (intuitive): lim_{x→a} f(x) = L means that if x is close to a (x ≠ a), then f(x) is close to L.
  • DNE ("does not exist"): f(x) does not approach one single number as x → a.
  • lim_{x→a} f(x) = ∞ (intuitive): if x is close to a (x ≠ a), then f(x) is arbitrarily large.

Notation & conventions

  • "DNE" is short for "does not exist."
  • Writing lim_{x→a} F(x) = ∞ says two things:
    1. the limit does NOT exist;
    2. it fails to exist in this specific way: F(x) grows arbitrarily large.
  • This looks contradictory and is arguably bad notation, but every calculus textbook uses it, so the course does too.
  • ∞ is not a number, so "the limit is ∞" does not mean the limit exists.
  • Trig functions use radians.

Theorems / facts

  • If f(x) keeps oscillating between two values in every neighbourhood of a, the limit at a does not exist.

Methods & proof templates

Example 3: h(x) = sin(π/(2x)). h(0) is undefined.

  • Table at x = 1, 1/2, 1/3, …, 1/8 (chosen so that the argument is a multiple of π/2): the values are 1, 0, −1, 0, 1, 0, −1, 0, …
  • As x → 0, h swings between −1 and 1 infinitely many times, faster and faster, on both sides of 0.
  • If x is close to 0, h(x) is not close to any single number, so lim_{x→0} h(x) DNE.

Example 4: F(x) = 1/(x−1)². F(1) is undefined, and there is a vertical asymptote at x = 1.

  • For x near 1 (x ≠ 1), (x−1)² is a small positive number, so 1/(x−1)² is huge (as large as we want).
  • So lim_{x→1} F(x) = ∞. In particular, the limit DNE.

Pitfalls & warnings

  • Do not read "lim = ∞" as "the limit exists and equals infinity." It is a specific way of failing to exist.
  • Plugging in a sequence of points that all give the same value (for example, only x = 1/(4k+1)) can hide oscillation. One single target number is required.

Exam-ready checklist

  • Explain why a limit must be a single real number.
  • Show that lim_{x→0} sin(π/(2x)) DNE by finding points close to 0 where the values are 1, 0 and −1.
  • Explain why lim_{x→1} 1/(x−1)² = ∞, and state that this limit DNE.
  • Use the "= ∞" notation correctly and explain what it means.

Big idea

A limit can fail to exist because f approaches one value from the right and a different value from the left. Side limits (one-sided limits) give a name to this. The video ends with a summary of every way a limit can exist or fail to exist.

Definitions

  • Right-hand limit (intuitive): lim_{x→a⁺} f(x) = L means that if x is close to a and x > a, then f(x) is close to L.
  • Left-hand limit (intuitive): lim_{x→a⁻} f(x) = L means that if x is close to a and x < a, then f(x) is close to L.
  • Limit exists: lim_{x→a} f(x) is a single real number.

Notation & conventions

  • A superscript + on the point (a⁺, e.g. 0⁺) means approaching from the right, through values > a.
  • A superscript − (a⁻, e.g. 0⁻) means approaching from the left, through values < a.
  • Read lim_{x→0⁺} as "the limit as x approaches 0 on the right."

Theorems / facts

  • What happens at a does not matter. The limit is the same whether f(a) is undefined, defined with the "wrong" value, or defined with the "right" value.
  • Ways a limit can fail to exist (DNE):
    • lim = ∞ (the function grows arbitrarily large);
    • lim = −∞;
    • the two side limits exist but are different;
    • something else, such as wild oscillation (sin(π/(2x)) near 0).
  • (Implicit) If the two side limits differ, the two-sided limit does not exist.

Methods & proof templates

Handling absolute values: split into cases by the sign of what is inside: |x| = x if x > 0, and |x| = −x if x < 0.

Example 5: G(x) = (x² + x)/|x|. G(0) is undefined.

  • For x > 0: G(x) = x(x+1)/x = x + 1.
  • For x < 0: G(x) = x(x+1)/(−x) = −x − 1.
  • The graph is two half-lines with open endpoints at (0, 1) and (0, −1).
  • Near 0, G(x) is sometimes close to 1 and sometimes close to −1, so lim_{x→0} G(x) DNE.
  • However, lim_{x→0⁺} G(x) = 1 and lim_{x→0⁻} G(x) = −1.

Pitfalls & warnings

  • "The limit DNE" is not the end of the analysis. Say how it fails (∞, −∞, different side limits, oscillation).
  • Do not confuse the + and − superscripts. + means from the right (x > a).

Exam-ready checklist

  • Compute one-sided limits of piecewise or absolute-value functions by splitting into cases.
  • Write the side-limit notation correctly and explain what it means.
  • List the different ways a limit can fail to exist, with an example of each.
  • Explain why the value f(a) does not affect lim_{x→a} f(x).

Big idea

"Close to" is made precise with absolute values: |x − a| is the distance between x and a. To be ready for the ε-δ definition, you need to move quickly between the equivalent forms of |x − a| < δ (in words, algebraically, and as a picture).

Definitions

  • Absolute value (algebraic): for every x ∈ ℝ, |x| = x if x ≥ 0, and |x| = −x if x < 0. (Zero can go in either case.)
  • Geometric interpretation: |x| is the distance between x and 0, and |x − a| is the distance between x and a.

Notation & conventions

  • In |x − a| < δ, all the variables are real numbers and δ > 0.

Theorems / facts

  1. |xy| = |x|·|y| for all x, y ∈ ℝ.
  2. The same is NOT true for sums. Instead there is the triangle inequality: |x + y| ≤ |x| + |y|.
  3. Equivalent statements (for δ > 0):
    • the distance between x and a is smaller than δ
    • ⇔ |x − a| < δ
    • ⇔ −δ < x − a < δ
    • ⇔ a − δ < x < a + δ
    • ⇔ x ∈ (a − δ, a + δ), an open interval centred at a (endpoints not included).

Methods & proof templates

  • To solve an equation or inequality that contains an absolute value, the usual method is to split into cases using the definition.
  • To get rid of an absolute value in an inequality, rewrite |u| < δ as −δ < u < δ. This gives two inequalities with no absolute value, which is usually easier algebra. Add a to every part to isolate x.

Pitfalls & warnings

  • |x + y| ≠ |x| + |y| in general. Only the inequality ≤ holds.
  • The interval (a − δ, a + δ) is open: the endpoints are excluded because the inequality is strict.

Exam-ready checklist

  • State the case definition of |x| and the meaning of |x − a| as a distance.
  • Convert |x − a| < δ ⇔ −δ < x − a < δ ⇔ a − δ < x < a + δ ⇔ x ∈ (a−δ, a+δ), and explain why each step holds.
  • Draw the number-line picture of |x − a| < δ.
  • Use |xy| = |x||y| and the triangle inequality.

Big idea

The intuitive idea "if x is close to a (x ≠ a), then f(x) is close to L" becomes a precise statement. Closeness is measured with the cut-offs δ and ε, and the quantifiers are chosen carefully: for every ε > 0 there exists δ > 0.

Definitions

Definition (limit). Let a, L ∈ ℝ. Let f be a function defined, at least, on an interval centred at a, except maybe at a. We say lim_{x→a} f(x) = L when

∀ε > 0, ∃δ > 0 s.t. (∀x ∈ ℝ,) 0 < |x − a| < δ ⇒ |f(x) − L| < ε.

How each piece is built:

  • "x is close to a" becomes "|x − a| is small", which becomes |x − a| < δ.
  • "but x ≠ a" becomes 0 < |x − a|. The distance is 0 only when x = a, so this rules that case out.
  • "f(x) is close to L" becomes |f(x) − L| < ε.

Notation & conventions

  • δ and ε are the traditional letters for the two cut-offs. Any letters would work.
  • Hidden quantifier: the implication carries an implied "∀x ∈ ℝ". By convention it is usually not written. You may write it explicitly if that helps, but remember it is always there.
  • "s.t." means "such that."
  • Before the definition starts, every symbol must be introduced (a, L, f). Otherwise the statement is meaningless.

Theorems / facts

Geometric meaning of the implication (for one fixed ε and δ):

  • Draw a vertical strip a − δ < x < a + δ (excluding x = a) and a horizontal band L − ε < y < L + ε.
  • Inside the strip, the graph must stay inside the band. The regions above and below the band within the strip are forbidden.
  • Outside the strip, f can do anything.

Methods & proof templates

Why these quantifiers:

  • The implication holding for one fixed pair (ε, δ) is not enough. A function with no limit (for example, one with a jump at a) can still avoid the forbidden regions for a large ε.
  • Requiring it for all ε and all δ is too much: for a given ε, some δ fail.
  • Making δ smaller never detects a missing limit. A smaller δ narrows the strip, so the condition becomes easier to satisfy.
  • Making ε small is what detects failure. For a jump function, a narrow enough band means no δ works.
  • So: for every ε > 0 (think "every small ε"; there is no smallest positive real), we need just one δ > 0 that works. δ may depend on ε, and as ε shrinks, δ usually has to shrink too.

Worked comparison (graphs):

  • A function with a limit: for each ε, however small, some δ keeps the graph in the band.
  • A function with a jump at a (lim DNE): this works for large ε, but once ε is smaller than half the jump, every δ fails.

Suggested exercise: write formal definitions for lim_{x→a⁺} f(x) = L, lim_{x→a⁻} f(x) = L, and lim_{x→a} f(x) = ∞ by adapting the pieces. (For example, use 0 < x − a < δ for the right-hand limit, a − δ < x < a for the left-hand limit, and for ∞ use ∀M ∈ ℝ, ∃δ > 0 s.t. 0 < |x − a| < δ ⇒ f(x) > M.)

Pitfalls & warnings

  • Do not memorize the definition as a string of symbols. Understand why each piece is needed. Leaving out or changing any small part (the 0 <, the order ∀ε∃δ, strict inequalities) changes the meaning completely.
  • The order of the quantifiers matters: ∀ε ∃δ, not ∃δ ∀ε.
  • The value f(a), or whether f(a) exists, plays no role. That is what the 0 < |x − a| is for.
  • f only needs to be defined on an interval around a, possibly with a itself missing.

Exam-ready checklist

  • Write the full ε-δ definition from memory, including the hypotheses on a, L and f, and explain the hidden ∀x.
  • Explain the role of each piece: 0 < |x−a|, < δ, |f(x)−L| < ε, ∀ε, ∃δ.
  • Draw the ε-band, δ-strip and forbidden-region picture, and use it to show that a jump function fails the definition.
  • Explain why a smaller δ makes the condition easier and a smaller ε makes it harder.
  • Adapt the definition to one-sided limits and to infinite limits.

Big idea

lim_{x→∞} f(x) = L means that f(x) gets as close to L as we want by taking x large enough. Geometrically, y = L is a horizontal asymptote. The formal version swaps the δ-condition for a cut-off M on x: "x > M".

Definitions

Intuitive idea: if x is very large, then f(x) is very close to L.

Definition (limit at infinity). Let L ∈ ℝ. Let f be a function defined, at least, on an interval of the form (p, ∞) for some p ∈ ℝ. We say lim_{x→∞} f(x) = L when

∀ε > 0, ∃M ∈ ℝ s.t. x > M ⇒ |f(x) − L| < ε.

How each piece is built:

  • "f(x) is close to L" becomes |f(x) − L| < ε.
  • "x is large" becomes x > M.

Horizontal asymptote at ∞: the line y = L when lim_{x→∞} f(x) = L.

Notation & conventions

  • "≈" (the squiggly equals sign) means "approximately."
  • M may depend on ε. When you choose ε, you then find an M for it. A smaller ε usually needs a bigger M.
  • (As in 2.5) there is a hidden "∀x" in front of the implication.
  • Interpretation: "If you tell me how close you want f(x) and L to be (ε), then I can tell you how large x must be (M)."

Theorems / facts

Geometric meaning: take the horizontal band L − ε < y < L + ε. To the right of x = M, the graph must stay inside the band; the regions above and below it are forbidden. To the left of M, the graph can be anywhere.

Methods & proof templates

Example: f(x) = (x + 1)/x = 1 + 1/x. As x → ∞, 1/x ≈ 0 (for example, x = 10⁶ gives 1/x = 10⁻⁶), so f(x) ≈ 1. Therefore lim_{x→∞} f(x) = 1, and y = 1 is a horizontal asymptote.

Why these quantifiers:

  • One fixed pair (ε, M) is not enough.
  • What matters is ε. Taking x larger than some M is easy and proves nothing, so we demand the condition for every ε > 0 (really, for every small ε).
  • For each ε, one M is enough, which gives ∃M.

Pitfalls & warnings

  • A common high-school myth: "an asymptote is a line the graph gets closer and closer to but never touches." This is wrong. The graph may touch or cross the asymptote, even infinitely many times (for example, a damped oscillation around y = L), and y = L is still a horizontal asymptote.
  • The domain must contain some interval (p, ∞). Otherwise "x large" makes no sense for f.

Exam-ready checklist

  • Write the formal definition of lim_{x→∞} f(x) = L, with its hypotheses on L and f.
  • Explain the roles of ε (closeness) and M (how large x must be), and why the quantifiers are ∀ε ∃M.
  • Draw the band and cut-off picture for the definition.
  • Find simple limits at infinity by rewriting (for example, (x+1)/x = 1 + 1/x).
  • Explain why a graph can cross its horizontal asymptote.

Big idea

A deliberately simple example, lim_{x→3} (2x+1) = 7, used to learn the structure of an ε–δ proof. The order of the steps comes straight from the order of the quantifiers in the definition. Finding δ is done separately in rough work, which is not part of the proof.

Definitions

  • lim_{x→3} (2x+1) = 7 means (formal definition of limit): ∀ε > 0, ∃δ > 0 s.t. ∀x ∈ ℝ, 0 < |x − 3| < δ ⇒ |(2x+1) − 7| < ε.

Notation & conventions

  • "WTS" = "want to show". Write out exactly what you need to prove before you start.
  • Wording for each quantifier:
    • ∀ε > 0 → "Let ε > 0" (or "Fix ε > 0"). ε is arbitrary: you don't choose it and you can't restrict it.
    • ∃δ > 0 → "Take δ = …" (or "Set"/"Let" δ = …). You choose δ, and it may depend on ε.
    • The implication → "Let x ∈ ℝ. Assume 0 < |x − 3| < δ." Then do some algebra and end with "… < ε, as needed."
  • Rough work ("What is δ?") goes on its own, separate from "The actual proof".

Theorems / facts

  • lim_{x→3} (2x+1) = 7, proved from the definition.

Methods & proof templates

Structure (it mirrors the quantifiers):

  1. Let ε > 0.
  2. Take δ = ??? (a function of ε, found in rough work).
  3. Let x ∈ ℝ. Assume 0 < |x − 3| < δ.
  4. … conclude |(2x+1) − 7| < ε.

Rough work (look only at the implication): |(2x+1) − 7| = |2x − 6| = 2|x − 3| < 2δ. To make this ≤ ε, set 2δ = ε, so δ = ε/2.

Actual proof:

  • Let ε > 0.
  • I take δ = ε/2.
  • Let x ∈ ℝ. Assume 0 < |x − 3| < δ.
  • Then |(2x+1) − 7| = |2x − 6| = 2|x − 3| < 2δ = ε. So |(2x+1) − 7| < ε, as needed. ∎

Each step is justified: "< 2δ" by the assumption on x, and "= ε" by the choice of δ.

Pitfalls & warnings

  • Order matters: fix ε first, then choose δ as a function of ε. If you mix up the order, it becomes unclear what is arbitrary and what was chosen. The result is a "pseudo-proof" that isn't actually a proof.

Notation & conventions

  • Same structure and wording as Example 1:
    1. Let (Fix) ε > 0.
    2. Take (Set/Let) δ = ???
    3. Let x ∈ ℝ. Assume 0 < |x − 4| < δ.
    4. Conclude |(x²+1) − 17| < ε.
  • δ may depend only on ε, never on x.
  • You choose δ, so you may impose as many conditions on it as you like (δ ≤ 1, δ ≤ ε/9, …). At the end you must produce one δ > 0 that meets all of them.
  • min{A, B} satisfies both "≤ A" and "≤ B". It is positive when A and B are both positive.

Rough work:

  • |(x²+1) − 17| = |x² − 16| = |x + 4| |x − 4| < |x + 4| δ.

  • I take δ = min{1, ε/9}. Therefore δ ≤ 1 and δ ≤ ε/9.

Big idea

To prove a limit does not exist, first build the formal statement of "limit DNE". Negate "lim = L", then put "∀L ∈ ℝ" in front. The result has four quantifiers and gives the proof skeleton. Worked example: h(x) = cos(πx) has no limit as x → ∞.

Definitions

  • lim_{x→∞} h(x) = L means: ∀ε > 0, ∃M ∈ ℝ s.t. (∀x ∈ ℝ,) x > M ⇒ |h(x) − L| < ε.
  • lim_{x→∞} h(x) ≠ L (the negation) means: ∃ε > 0 s.t. ∀M ∈ ℝ, ∃x ∈ ℝ s.t. [x > M and |h(x) − L| ≥ ε].
  • lim_{x→∞} h(x) DNE means it is not equal to any real number: ∀L ∈ ℝ, ∃ε > 0 s.t. ∀M ∈ ℝ, ∃x ∈ ℝ s.t. x > M and |h(x) − L| ≥ ε.

Notation & conventions

  • How to negate the definition:
    • ∀ becomes ∃ and ∃ becomes ∀.
    • The implication has a hidden "∀x ∈ ℝ". Its negation is "∃x".
    • The negation of "P ⇒ Q" is "P and not Q". So "x > M ⇒ |h(x) − L| < ε" becomes "x > M and |h(x) − L| ≥ ε".
  • "DNE" = "for every L, the limit is not L". This is why ∀L goes in front.
  • Each quantifier gives one line of the proof:
    1. Let L ∈ ℝ (arbitrary).
    2. Take ε = … (you choose it; it may depend on L).
    3. Let M ∈ ℝ (arbitrary).
    4. Take x = … (you choose it; it may depend on L and M).
    5. Verify x > M and |h(x) − L| ≥ ε.
  • Once the proof is written, check that its "Let/Take" lines match the structure you worked out from the statement.

Theorems / facts

  • lim_{x→∞} cos(πx) does not exist.
  • Useful facts: cos(πx) = 1 when x is an even integer, and cos(πx) = −1 when x is an odd integer.
  • If ε ≤ 1, the open interval (L − ε, L + ε) cannot contain both 1 and −1. Containing both would need width > 2, so ε > 1.
  • There are integers (even or odd) as large as you want, so one can always be found > M.

Methods & proof templates

Rough work (graphical): draw the band between L − ε and L + ε. You need some x to the right of M with h(x) outside the band. ε must be small enough that the band doesn't cover all of [−1, 1]. Any ε ≤ 1 works. Then pick an integer x > M, so that h(x) = ±1 lands outside the band.

Proof:

  • Let L ∈ ℝ. Take ε = 1/2. Let M ∈ ℝ.
  • At least one of these is true:
    • Case A: 1 ∉ (L − ε, L + ε). Choose any even integer x > M. Then h(x) = 1.
    • Case B: −1 ∉ (L − ε, L + ε). Choose any odd integer x > M. Then h(x) = −1.
  • Either way, x > M and |h(x) − L| ≥ ε. ∎

Remarks:

  • ε could have depended on L, but here it didn't need to.
  • You don't need an explicit formula for x (floor/ceiling). Saying "any even integer > M" is clear and rigorous enough.

Pitfalls & warnings

  • Don't forget the hidden ∀x when negating an implication. Its negation is ∃x … and …, not another implication.
  • "≠ L" is not "DNE". You must also quantify over every L.
  • The negation of "< ε" is "≥ ε" (not "> ε").
  • Choosing ε too large (> 1 here) makes the proof impossible.
  • Keep the order: L arbitrary → choose ε → M arbitrary → choose x.

Exam-ready checklist

  • Negate the definition of lim_{x→a} f(x) = L or lim_{x→∞} f(x) = L correctly, including the hidden ∀x.
  • Write out "lim DNE" with all four quantifiers.
  • Turn it into the five-step skeleton (Let L / Take ε / Let M (or δ) / Take x / verify).
  • Use a picture to choose ε small enough, and an x that escapes the band.
  • Handle "at least one of two cases" arguments cleanly.

Big idea

We don't want to do an ε–δ proof for every polynomial. Instead, prove two basic limits (lim x = a and lim c = c) and the limit laws (sum, product, quotient) once. After that, the limit of any polynomial is found by plugging in, and that method is rigorously justified. The limit laws only apply when the individual limits exist.

Definitions

  • Polynomials are built from the "building blocks" x and constants c using only sums and products.

Notation & conventions

  • The limit laws are "IF … THEN …" theorems. The hypothesis is that each individual limit exists and is a real number.

Theorems / facts

  • Basic limits (provable straight from ε–δ; left as an exercise, the easiest ε–δ proofs there are). For every a, c ∈ ℝ:
    • lim_{x→a} x = a
    • lim_{x→a} c = c
  • Limit laws. Assume lim_{x→a} f(x) = L and lim_{x→a} g(x) = M (L, M ∈ ℝ). Then:
    • Sum: lim_{x→a} [f(x) + g(x)] = L + M
    • Product: lim_{x→a} [f(x)g(x)] = LM
    • Quotient: lim_{x→a} [f(x)/g(x)] = L/M, assuming M ≠ 0
  • Consequence: for every polynomial P and every a ∈ ℝ, lim_{x→a} P(x) = P(a).

Methods & proof templates

Plan to prove lim P(x) = P(a) for all polynomials:

  1. Prove the two basic limits from the definition.
  2. Prove the sum and product laws.
  3. Break any polynomial into sums and products of x and constants, apply the laws, and finish with the basic limits.

Example: lim_{x→2} (x⁴ − 3x) = (lim_{x→2} x⁴) + (lim_{x→2} [−3x]) (sum law) = (lim_{x→2} x)⁴ + (lim_{x→2} (−3))(lim_{x→2} x) (product law) = 2⁴ − 3·2 = 10 (basic limits).

Pitfalls & warnings

  • The limit laws only apply if the initial limits exist. If you don't know that each piece has a limit, you can conclude nothing, positive or negative.
    • lim_{x→0} x = 0 and lim_{x→0} 3/x DNE, but lim_{x→0} [x · 3/x] = 3. "0 · DNE" could be anything.
    • lim_{x→0} 1/x and lim_{x→0} (2x−1)/x both DNE, but lim_{x→0} [1/x + (2x−1)/x] = lim 2x/x = 2.
  • The quotient law needs M ≠ 0.

Exam-ready checklist

  • State the sum, product and quotient laws with all their hypotheses (limits exist; M ≠ 0).
  • Prove lim_{x→a} x = a and lim_{x→a} c = c from the definition (take δ = ε, and δ = anything respectively).
  • Justify each step of a polynomial limit computation by naming the law used.
  • Give counterexamples showing that a sum or product can have a limit when its pieces don't.

Big idea

An ε–δ proof where you use hypotheses that are themselves limits. Each known limit is used with ε/2 as its "ε". That produces δ₁ and δ₂. Take δ = min{δ₁, δ₂}, then finish with the triangle inequality.

Definitions

  • Goal (with h(x) := f(x) + g(x)): lim_{x→a} h(x) = L + M means ∀ε > 0, ∃δ > 0 s.t. ∀x ∈ ℝ, 0 < |x − a| < δ ⇒ |h(x) − (L + M)| < ε.

Notation & conventions

  • Precise statement: introduce every variable. Let a, L, M ∈ ℝ. Let f and g be functions defined at least on an interval centred at a, except maybe at a.
  • Naming h = f + g is just a shorthand.
  • Using the definition of limit for the goal vs. for a hypothesis:
    • For the goal (h), which you want to show: ε is given to you as arbitrary, and you must produce δ.
    • For a hypothesis (f), which you know: you may choose any ε you like (e.g. ε/2), and a δ is guaranteed to exist for you.
  • Each hypothesis gives its own δ. Give them different names (δ₁, δ₂); they need not be equal.

Theorems / facts

  • Theorem (sum law). Let a, L, M ∈ ℝ, and let f, g be defined on an interval centred at a, except maybe at a. IF lim_{x→a} f(x) = L and lim_{x→a} g(x) = M, THEN lim_{x→a} [f(x) + g(x)] = L + M.
  • Triangle inequality: |A + B| ≤ |A| + |B|.
  • The minimum of two positive numbers is positive. If |x − a| < min{δ₁, δ₂}, then |x − a| < δ₁ and |x − a| < δ₂.

Methods & proof templates

Rough work: |h(x) − (L+M)| = |[f(x) − L] + [g(x) − M]| ≤ |f(x) − L| + |g(x) − M|. It is enough to make each term < ε/2.

  • Plug ε/2 into the definition of lim f = L: ∃δ₁ > 0 with 0 < |x − a| < δ₁ ⇒ |f(x) − L| < ε/2.
  • Same for g: ∃δ₂ > 0 with 0 < |x − a| < δ₂ ⇒ |g(x) − M| < ε/2.
  • Take δ = min{δ₁, δ₂}.

Proof:

  • Let ε > 0.
  • I use ε/2 in the definition of lim_{x→a} f(x) = L: ∃δ₁ > 0 s.t. 0 < |x − a| < δ₁ ⇒ |f(x) − L| < ε/2.
  • I use ε/2 in the definition of lim_{x→a} g(x) = M: ∃δ₂ > 0 s.t. 0 < |x − a| < δ₂ ⇒ |g(x) − M| < ε/2.
  • Take δ = min{δ₁, δ₂}.
  • Let x ∈ ℝ. Assume 0 < |x − a| < δ. This implies:
    • 0 < |x − a| < δ₁, thus |f(x) − L| < ε/2;
    • 0 < |x − a| < δ₂, thus |g(x) − M| < ε/2.
  • Then |h(x) − (L+M)| = |[f(x) − L] + [g(x) − M]| ≤ |f(x) − L| + |g(x) − M| < ε/2 + ε/2 = ε.
  • I have shown |h(x) − (L+M)| < ε, as needed. ∎

The skeleton (Let ε / Take δ / Let x, assume / conclude) is the same as in the earlier examples.

Pitfalls & warnings

  • Order of introduction: fix ε first. Only then can you use ε/2 in the hypotheses, which gives δ₁ and δ₂. Only after that can you define δ. Saying "use ε/2" before ε is fixed makes no sense.
  • Don't assume the two hypotheses give the same δ.
  • Don't confuse the two roles of the definition. You can't choose ε for the goal, and you don't have to construct δ for a hypothesis.
  • Rough work is not the proof. Write the final version in logical order, so the reasoning isn't circular.

Exam-ready checklist

  • State the sum law precisely (variables, domain condition, hypotheses, conclusion).
  • Reproduce the full ε/2 + min{δ₁, δ₂} proof from memory.
  • Explain the difference between using a known limit and proving a limit.
  • Adapt the ε/2 trick to similar proofs (e.g. a difference, or lim [cf(x)] = cL).

Big idea

Sometimes a limit can't be split with the product law because one factor has no limit, as with sin(1/x) at 0. If the function is trapped between two functions that have the same limit L, then it also has limit L. Main example: lim_{x→0} x² sin(1/x) = 0. (The proof of the theorem is in the next video.)

Definitions

  • "Exists" for a limit means it equals a real number.

Notation & conventions

  • Precise statement: introduce every variable first. Let a, L ∈ ℝ. Let f, g, h be functions defined near a, except possibly at a.
  • The inequalities only need to hold for x close to a but not at a. What happens at a doesn't matter.
  • Keep the picture in mind: an upper curve f and a lower curve h meet at (a, L), and g is sandwiched between them.

Theorems / facts

  • Product law (recalled): IF lim_{x→a} f(x) = L ∈ ℝ and lim_{x→a} g(x) = M ∈ ℝ, THEN lim_{x→a} [f(x)·g(x)] = L·M.
  • Squeeze Theorem. Let a, L ∈ ℝ, and let f, g, h be defined near a, except possibly at a. IF
    • for x close to a but not a: h(x) ≤ g(x) ≤ f(x),
    • lim_{x→a} f(x) = L, and
    • lim_{x→a} h(x) = L, THEN lim_{x→a} g(x) = L.
  • lim_{x→0} sin(1/x) DNE. It oscillates wildly between −1 and 1.
  • For every x ≠ 0: −1 ≤ sin(1/x) ≤ 1, so −x² ≤ x² sin(1/x) ≤ x².

Methods & proof templates

Template for using the Squeeze Theorem:

  1. Find a bounded "bad" factor (e.g. −1 ≤ sin(·) ≤ 1, or −1 ≤ cos(·) ≤ 1).
  2. Multiply it by the "good" factor to get a lower bound and an upper bound valid near a (x ≠ a). Be careful with signs; here x² ≥ 0.
  3. Show that both bounds have the same limit L.
  4. Conclude "By the Squeeze Theorem, lim g = L."

Worked example (a correct solution): compute lim_{x→0} x² sin(1/x).

  • We know: for every x ≠ 0, −x² ≤ x² sin(1/x) ≤ x².
  • lim_{x→0} x² = 0 and lim_{x→0} (−x²) = 0.
  • By the Squeeze Theorem, lim_{x→0} x² sin(1/x) = 0.

Pitfalls & warnings

  • Incorrect solution (a trap): "lim [x² sin(1/x)] = [lim x²]·[lim sin(1/x)] = 0·[lim sin(1/x)] = 0." This is wrong because the product law requires both limits to exist, and lim_{x→0} sin(1/x) does not. The final answer happens to be 0, but the argument is invalid.
  • "0 · (DNE)" tells you nothing:
    • lim x = 0, lim 3/x DNE, but lim [x · 3/x] = 3;
    • lim x = 0, lim 3/x² DNE, and lim [x · 3/x²] = lim 3/x also DNE.
  • Both bounding functions must have the same limit. If their limits differ, you can't conclude anything.

Exam-ready checklist

  • State the Squeeze Theorem precisely, including "defined near a except possibly at a" and "for x close to a but not a".
  • Explain why the "limit of product" shortcut fails for x² sin(1/x).
  • Apply the Squeeze Theorem to x^n sin(1/x), x cos(1/x), and similar limits, writing the bounds and both limits explicitly.
  • Give examples where one factor → 0 and the other DNE, but the product has a limit, or doesn't.

Big idea

A full ε–δ proof of the Squeeze Theorem. The point of the video is the technique: when you are proving a limit you fix an arbitrary ε, and when you are using a limit you already know, you pick an ε that suits you (here, the same ε) and get a δ for free. Then you take δ to be the minimum of all the δ's you collected.

Definitions

  • Limit (recall): lim_{x→a} g(x) = L means ∀ε > 0, ∃δ > 0 s.t. ∀x ∈ ℝ, 0 < |x − a| < δ ⇒ |g(x) − L| < ε.
  • "For x close to a, but not a" is written formally as: ∃p > 0 s.t. 0 < |x − a| < p ⇒ (the property holds).

Notation & conventions

  • |g(x) − L| < ε ⇔ L − ε < g(x) < L + ε. You will keep switching between these two forms.
  • Name the δ's that come from known limits δ₁, δ₂, … (and the radius from the sandwich hypothesis p), so they stay separate from the δ you have to build.
  • Rough work is not part of the proof. The real proof starts afterwards and has to be written in logical order.
  • Proof skeleton words: "Let (Fix) ε > 0", "Take (Set/Let) δ = …", "Let x ∈ ℝ. Assume 0 < |x − a| < δ", "…we have shown |g(x) − L| < ε."

Theorems / facts

Squeeze Theorem (formal version). Let a, L ∈ ℝ. Let f, g, h be defined near a, except possibly at a. IF

  1. ∃p > 0 s.t. 0 < |x − a| < p ⇒ h(x) ≤ g(x) ≤ f(x),
  2. lim_{x→a} f(x) = L,
  3. lim_{x→a} h(x) = L,

THEN lim_{x→a} g(x) = L.

(Saying "for x close to a, but not a, h ≤ g ≤ f" means the same as hypothesis 1. The ∃p form is just more precise, which makes the proof easier to write.)

  • The minimum of finitely many positive numbers is positive, so δ = min{δ₁, δ₂, p} > 0.

Methods & proof templates

What you are proving vs. what you are assuming:

  • Goal (lim g = L): you fix an arbitrary ε and must find a δ that works for it.
  • Hypotheses (lim f = L, lim h = L): nothing to prove. You may choose any ε you like, and a δ that works for it is guaranteed to exist. (The proof of the sum limit law uses the same idea.)

Rough work (finding δ):

  1. Goal: 0 < |x − a| < δ ⇒ L − ε < g(x) < L + ε.
  2. On 0 < |x − a| < p we know h(x) ≤ g(x) ≤ f(x), so it is enough to bound h from below and f from above.
  3. Use the same ε in lim f = L: ∃δ₁ > 0, 0 < |x−a| < δ₁ ⇒ L − ε < f(x) < L + ε. (You only need f(x) < L + ε.)
  4. Use the same ε in lim h = L: ∃δ₂ > 0, 0 < |x−a| < δ₂ ⇒ L − ε < h(x) < L + ε. (You only need h(x) > L − ε.)
  5. You need all three conditions at once, so take δ = min{δ₁, δ₂, p}.

Final proof:

  • Let ε > 0.
  • Apply lim f = L with this ε: ∃δ₁ > 0 with 0 < |x−a| < δ₁ ⇒ |f(x) − L| < ε ⇒ f(x) < L + ε.
  • Apply lim h = L with this ε: ∃δ₂ > 0 with 0 < |x−a| < δ₂ ⇒ |h(x) − L| < ε ⇒ L − ε < h(x).
  • Take δ = min{δ₁, δ₂, p} (positive).
  • Let x ∈ ℝ and assume 0 < |x − a| < δ. Then:
    • |x − a| < δ₂, so L − ε < h(x);
    • |x − a| < p, so h(x) ≤ g(x) ≤ f(x);
    • |x − a| < δ₁, so f(x) < L + ε.
  • Chain these: L − ε < h(x) ≤ g(x) ≤ f(x) < L + ε, so |g(x) − L| < ε. ∎

Pitfalls & warnings

  • Don't treat the hypotheses like the goal. You don't "fix an arbitrary ε" for lim f; you choose one.
  • Don't hand in the rough work as the proof. Rewrite it in order so that every variable is introduced before it is used and nothing is circular.
  • δ has to work for every condition at once. Taking only min{δ₁, δ₂} and forgetting p is a mistake, because then the sandwich inequality might not hold.
  • From each known limit, keep only the half of the inequality you need. Extra pieces are fine but just clutter the proof.

Exam-ready checklist

  • State the Squeeze Theorem precisely, writing the "near a" hypothesis with ∃p > 0.
  • Write the ε–δ skeleton for a limit you are trying to prove.
  • Explain the difference between using a limit as a hypothesis (choose ε, get δ) and proving one (fix ε, find δ).
  • Combine several δ's with δ = min{…} and say why the result is positive.
  • Reproduce the full Squeeze Theorem proof from memory, in the correct logical order.

Big idea

"Continuous" roughly means you can draw the graph without lifting the pen. Made rigorous, f is continuous at a when lim_{x→a} f(x) = f(a). The video gives an equivalent ε–δ version, explains the main difference from a plain limit (x = a is no longer excluded), and defines continuity on open intervals, on closed intervals, and "on its domain".

Definitions

  • Continuity at a point. Let a ∈ ℝ and let f be defined (at least) on an interval centred at a. f is continuous at a when lim_{x→a} f(x) = f(a). This packs in three conditions:
    1. lim_{x→a} f(x) exists (it is a number);
    2. f(a) is defined;
    3. the two are equal.
  • ε–δ definition of continuity (equivalent). f is continuous at a ⇔ ∀ε > 0, ∃δ > 0 s.t. ∀x, |x − a| < δ ⇒ |f(x) − f(a)| < ε. To get this, replace L with f(a) in the limit definition. Then the condition "0 <" can be dropped: when x = a, |f(a) − f(a)| = 0 < ε holds automatically.
  • Continuous on an open interval. f is continuous on (a, b) means ∀c ∈ (a, b), f is continuous at c.
  • Continuous on a closed interval. f is continuous on [a, b] means
    1. lim_{x→a⁺} f(x) = f(a) (only the right-hand limit at the left endpoint),
    2. ∀c ∈ (a, b), f is continuous at c,
    3. lim_{x→b⁻} f(x) = f(b) (only the left-hand limit at the right endpoint).
  • "f is continuous" with no location given means continuous on its domain.

Notation & conventions

  • In the definition, both sides of lim f(x) = f(a) have to be the same number. If both fail to exist, that does not count as "equal".
  • One-sided limits at the endpoints of a closed interval are needed because f may not be defined outside [a, b], so the two-sided limit there isn't even defined (example: a semicircle on [a, b]).
  • Domains other than intervals get similar case-by-case definitions. Later courses (e.g. multivariable calculus) use a single definition that covers every domain, but this course doesn't need it.

Theorems / facts

  • The two definitions (limit form and ε–δ form) are entirely equivalent. Use whichever is more convenient.
  • Limit vs continuity (intuition, not rigorous):
    • lim_{x→a} f(x) = L: if x is close to a, but not a, then f(x) is close to L.
    • f continuous at a: if x is close to a, including a, then f(x) is close to f(a).
  • Ways a graph can fail to be drawable "in one go":
    • Hole: the limit exists but f(a) is undefined, or f(a) is defined but ≠ the limit. Both count as not continuous.
    • Jump: no limit.
    • Vertical asymptote: no limit.
    • Wild oscillation (e.g. near 0): no limit.

Methods & proof templates

  • To check continuity at a: (1) compute lim_{x→a} f(x) and check it exists; (2) check f(a) is defined; (3) compare them.
  • To prove continuity with ε–δ: same skeleton as a limit proof (Let ε > 0; take δ = …; let x ∈ ℝ with |x − a| < δ; show |f(x) − f(a)| < ε). The hypothesis no longer needs "0 <".
  • On [a, b]: check the interior points as usual, then check a one-sided limit at each endpoint.

Pitfalls & warnings

  • A function can be continuous (on its domain) and still not continuous at 1. Example: a function with a vertical asymptote at x = 1, where 1 is not in the domain. This is not a contradiction once you apply the definitions precisely.
  • An undefined f(a) and a "wrong" f(a) are both discontinuities.
  • At an endpoint of a closed interval, don't require the two-sided limit. It usually doesn't exist because f isn't defined on the other side.
  • The pen-on-paper picture is only intuition. On a test, use the limit definition.

Exam-ready checklist

  • State the definition of continuity at a point, including its hypotheses (a ∈ ℝ, f defined on an interval centred at a).
  • Write the ε–δ definition of continuity and explain why "0 < |x − a|" can be dropped.
  • Explain in words how "limit = L" differs from "continuous at a" (excluding vs including x = a).
  • Define continuity on (a, b) and on [a, b] using one-sided limits at the endpoints.
  • Interpret "f is continuous" as "continuous on its domain" and explain the asymptote example.

Big idea

Almost every function you normally write down (built from polynomials, roots, trig, exponentials, logs and absolute values) is continuous on its domain. So at any point of the domain, a limit can be computed by plugging in. The proof reduces to six basic functions plus closure under sum, product, quotient and composition.

Definitions

  • Recall: f is continuous at c when lim_{x→c} f(x) = f(c). In other words, taking the limit is the same as evaluating.
  • Elementary functions: the class of functions built with sum, product, quotient and composition from polynomials, roots, trig functions, exponentials, logarithms and absolute values. ("Elementary" is just the name of the class. It doesn't mean easy.)

Notation & conventions

  • "Continuous" with no location given means continuous on its domain (from 2.14). The theorem is stated in that sense.

Theorems / facts

Main Continuity Theorem. Any function built with sum, product, quotient and composition from polynomials, roots, trigonometric functions, exponentials, logarithms and absolute values is continuous on its domain.

The 6 basic functions (everything else is built from these): f(x) = c, f(x) = x, f(x) = eˣ, f(x) = ln x, f(x) = sin x, f(x) = |x|.

  • cos x = sin(π/2 − x) (composition of sin with a polynomial)
  • tan x = sin x / cos x (quotient)
  • 2ˣ = e^{x ln 2}, and more generally any base: compose eˣ with other functions
  • √x = e^{(1/2) ln x}
  • Polynomials come from constants and x using sums and products.

Closure facts: if f and g are continuous at a, then f + g, f·g and f/g (when g(a) ≠ 0) are continuous at a. Composition is also true but needs a separate argument (see 2.16).

Methods & proof templates

Strategy for proving the theorem:

  • Step 1: prove the 6 basic functions are continuous. (This was not done in the video; it can be done.)
  • Step 2: prove that sums, products, quotients and compositions of continuous functions are continuous.

Proof that a sum of continuous functions is continuous (from the limit laws):

  • Assume f and g are continuous at a, i.e. lim_{x→a} f(x) = f(a) and lim_{x→a} g(x) = g(a).
  • By the limit law for sums, lim_{x→a} [f(x) + g(x)] = f(a) + g(a) = (f + g)(a).
  • So f + g is continuous at a by definition. ∎
  • Products and quotients work exactly the same way, using their limit laws.

Worked example (plug in): lim_{x→1} (x² − sin x) / (eˣ + ln(√x + 3)) = (1 − sin 1)/(e + ln 4). This works because the function is elementary and 1 is in its domain.

Pitfalls & warnings

  • The theorem only applies on the domain. Not every limit of an elementary function can be found by plugging in:
    • f(x) = sin x / x is not continuous at 0 because 0 is not in its domain, so lim_{x→0} needs other methods.
    • tan x is not continuous at π/2 because π/2 is not in its domain.
  • There is no limit law for composition, so step 2 for compositions can't be done like the sum case. It needs the continuity-specific argument in 2.16.

Exam-ready checklist

  • State the Main Continuity Theorem, including the words "on its domain".
  • Use it to justify computing a limit by substitution, after checking the point is in the domain.
  • Recognise when it does not apply (the point is not in the domain).
  • List the 6 basic functions and write cos, tan, aˣ and √x in terms of them.
  • Prove that sums, products and quotients of continuous functions are continuous using the limit laws.

Big idea

Composition works well with continuity but not with plain limits. If you only know that f and g have limits, you can't conclude anything about the limit of g∘f. The reason is that a limit ignores the point itself ("x ≠ a") while continuity includes it, so the implications don't chain together. There are two ways to repair the false theorem: strengthen the hypothesis on f (Theorem 2) or on g (Theorem 3).

Definitions

  • (Recall) lim_{x→a} f(x) = L; f continuous at a ⇔ lim_{x→a} f(x) = f(a).
  • Intuitive readings:
    • lim_{x→a} f(x) = L: {x close to a, x ≠ a} ⇒ f(x) close to L.
    • f continuous at a: x close to a ⇒ f(x) close to f(a). Input and output are treated symmetrically ("close to" on both sides with nothing excluded).

Notation & conventions

  • Use a different variable for the outer function, e.g. lim_{y→L} g(y) = M. This makes it clear that y stands for the output f(x).
  • Theorems are written with numbered hypotheses (1), (2) and conclusion (3).

Theorems / facts

  • Limit laws exist for sums and products (when the individual limits exist). There is NO limit law for composition.

FALSE "Theorem": IF (1) lim_{x→a} f(x) = L and (2) lim_{y→L} g(y) = M, THEN (3) lim_{x→a} g(f(x)) = M. This is false. Nothing can be concluded.

Counterexample:

  • f(x) = x sin(π/x) for x ≠ 0, and f(0) = 0. Then lim_{x→0} f(x) = 0 (Squeeze: −|x| ≤ f(x) ≤ |x|).
  • g(y) = 2 if y = 0, and g(y) = 1 if y ≠ 0. Then lim_{y→0} g(y) = 1.
  • lim_{x→0} g(f(x)) does not exist. (The video leaves this as an exercise. Worked out: f(x) = 0 exactly when x = 0 or sin(π/x) = 0, i.e. x = 1/k with k ∈ ℤ∖{0}. So g(f(x)) = 2 if x = 0 or x = 1/k, and g(f(x)) = 1 otherwise. Every interval around 0 contains points where g∘f = 2 (x = 1/k) and points where g∘f = 1, so there is no limit.)

Theorem 1 (composition of continuous functions). IF (1) f is continuous at a and (2) g is continuous at f(a), THEN (3) g∘f is continuous at a. (This finishes the Main Continuity Theorem from 2.15.)

Theorem 2 (stronger hypothesis on f). IF (1) lim_{x→a} f(x) = L and f(x) ≠ L for all x in some interval centred at a, except possibly at a, and (2) lim_{y→L} g(y) = M, THEN (3) lim_{x→a} g(f(x)) = M.

Theorem 3 (stronger hypothesis on g). IF (1) lim_{x→a} f(x) = L and (2) g is continuous at L, THEN (3) lim_{x→a} g(f(x)) = g(L).

Methods & proof templates

The "concatenate implications" heuristic (the lecturer finds it more illuminating than a formal proof):

  • Theorem 1: (1) x close to a ⇒ f(x) close to f(a). (2) y close to f(a) ⇒ g(y) close to g(f(a)). Substitute y = f(x): x close to a ⇒ g(f(x)) close to g(f(a)), which is (3). ✓
  • False theorem: (1) {x close to a, x ≠ a} ⇒ f(x) close to L. (2) {y close to L, y ≠ L} ⇒ g(y) close to M. The output of (1) doesn't guarantee f(x) ≠ L, so it doesn't match the input of (2). The implications can't be concatenated. ✗
  • Theorem 2 fixes the mismatch by adding f(x) ≠ L near a.
  • Theorem 3 fixes it by removing the "y ≠ L" requirement in (2), since continuity includes y = L.
  • Suggested exercise: write the hypotheses of Theorems 2 and 3 as implications and check that they chain together.

Challenge from the video: build f with lim_{x→0} f(x) = 0 but lim_{x→0} f(f(x)) = 1. (One solution, not given in the video: f(x) = 0 for x ≠ 0 and f(0) = 1. Then for x ≠ 0, f(f(x)) = f(0) = 1.)

Pitfalls & warnings

  • Don't write "lim g(f(x)) = lim_{y→L} g(y)" automatically. Without continuity of g at L, or f(x) ≠ L near a, the step is invalid.
  • In Theorem 3 the conclusion is g(L), not just "some M".
  • The only difference between a limit and continuity is whether x = a is excluded, and that difference is exactly what breaks composition.

Exam-ready checklist

  • State the false theorem and give a counterexample (the g∘f above, or the challenge function).
  • Show why lim_{x→0} g(f(x)) does not exist in the counterexample.
  • State Theorems 1, 2 and 3 with all hypotheses and conclusions.
  • Explain with the concatenation heuristic why Theorems 1–3 hold and the false theorem fails.
  • Use Theorem 3 to justify moving a limit inside a continuous function: lim g(f(x)) = g(lim f(x)).

Big idea

A discontinuity at a is either removable (the limit exists but isn't f(a)), which you can fix by redefining the function at a single point, or non-removable (the limit doesn't exist), which no choice of f(a) can fix.

Definitions

  • f is discontinuous at a if it is not continuous at a, i.e. lim_{x→a} f(x) = f(a) fails.
  • Removable discontinuity at a: lim_{x→a} f(x) exists, but lim_{x→a} f(x) ≠ f(a). This includes the case where f(a) is undefined.
  • Non-removable discontinuity at a: lim_{x→a} f(x) does not exist.

Notation & conventions

  • On a graph, a removable discontinuity is a hole. It makes no difference whether f(a) is undefined or defined with the "wrong" value. Both are removable.
  • Removing a discontinuity means defining a new function (e.g. capital H) that agrees with the old one for x ≠ a and sets its value at a equal to the limit.
  • Physicists usually remove discontinuities automatically and don't distinguish between the original function and the fixed one. For example, "sin x / x" in physics usually means the fixed function H. In this course, keep the distinction.

Theorems / facts

  • If lim_{x→a} f(x) = L exists, the function F(x) = f(x) for x ≠ a and F(a) = L is continuous at a. This is always possible when the limit exists, which is where the name "removable" comes from.
  • If the limit does not exist, no value of f(a) makes f continuous at a.
  • Types of non-removable discontinuity shown:
    • Jump (different one-sided limits, e.g. at 0);
    • Vertical asymptote (e.g. at x = 1);
    • Wild oscillation (e.g. near 0; the graph from the video looks like sin(1/x)-type behaviour).

Methods & proof templates

Classifying a discontinuity at a:

  1. Does lim_{x→a} f(x) exist? If not, the discontinuity is non-removable.
  2. If it exists, is f(a) defined and equal to the limit? If yes, f is continuous at a. If not, the discontinuity is removable.

Worked example: h(x) = sin x / x. Then lim_{x→0} h(x) = 1 (proved in a later video) and h(0) is undefined, so h has a removable discontinuity at 0. Fix it with H(x) = sin x / x if x ≠ 0, and H(0) = 1. H is continuous at 0, and its graph is h's graph with the hole filled.

Pitfalls & warnings

  • A defined f(a) doesn't mean f is continuous at a. If f(a) ≠ lim f(x), there is still a (removable) discontinuity.
  • h and H are different functions (H is defined at 0, h is not), even though their graphs differ by only one point.
  • Jumps, asymptotes and oscillation can't be fixed by redefining one point, because the limit doesn't exist.

Exam-ready checklist

  • Define removable and non-removable discontinuities precisely in terms of lim_{x→a} f(x) and f(a).
  • Classify a discontinuity from a formula or a graph (hole, jump, asymptote, oscillation).
  • Remove a removable discontinuity by writing the piecewise "fixed" function, as with H for sin x / x.
  • Explain why non-removable discontinuities can't be fixed.

Big idea

We prove lim_{x→0} sin(x)/x = 1 using only high-school geometry. Comparing three areas in the unit circle traps sin(x)/x between cos x and 1/cos x, and then the Squeeze Theorem gives the limit.

Definitions

  • Unit circle: the circle of radius 1 centred at the origin O. Take the point A on the circle at angle x, measured counterclockwise from the positive horizontal axis. Then A = (cos x, sin x). The lecturer regards this as the best definition of sine and cosine.
  • Setup:
    • B is the foot of the vertical line from A to the horizontal axis, so |AB| = sin x and |OB| = cos x.
    • D = (1, 0) is the rightmost point of the circle.
    • C is the point on the ray OA directly above D, so |CD| = tan x (because |OD| = 1 in triangle OCD).

Notation & conventions

  • Angles are in radians. The sector-area formula and the limit itself depend on this.
  • "Sandwiched" or "squeezed" means g(x) ≤ f(x) ≤ h(x) for all x near the point, but not necessarily at the point.

Theorems / facts

  • Area of a circular sector with radius R and angle x: S = ½·x·R².
    • Derivation: the area is proportional to the angle (doubling the angle doubles the area), so S = k·x for some constant k.
    • The full circle is the sector with x = 2π and area πR², so πR² = k·2π, which gives k = R²/2.
  • Key inequality: cos x ≤ sin(x)/x ≤ 1/cos x for 0 < |x| < π/2.
    • It also holds for negative x, for either of two reasons:
      • Redo the picture in the fourth quadrant, taking care with signs.
      • All three functions are even, so replacing x by −x changes nothing.
    • The inequality is not stated at x = 0, because we divided by x.
  • Theorem: lim_{x→0} sin(x)/x = 1.
    • The outer functions cos x and 1/cos x are continuous at 0 with value 1.
    • So by the Squeeze Theorem the middle function also has limit 1.
    • sin(x)/x is undefined at 0, but that does not matter for the limit.

Methods & proof templates

Proof (for 0 < x < π/2):

  1. Draw three nested regions: triangle OAB ⊆ sector OAD ⊆ triangle OCD.
  2. Compute the three areas:
    • Area(OAB) = ½·cos x·sin x
    • Area(OAD) = ½·x·1² = x/2
    • Area(OCD) = ½·1·tan x
  3. Since the regions are nested: ½ cos x sin x ≤ x/2 ≤ ½ tan x.
  4. Multiply by 2: cos x·sin x ≤ x ≤ sin x / cos x.
  5. Rearrange each half separately. Every step multiplies or divides by a positive quantity, so the inequalities keep their direction.
    • From the left half: sin x / x ≤ 1/cos x.
    • From the right half: cos x ≤ sin x / x.
  6. Combine: cos x ≤ sin(x)/x ≤ 1/cos x for 0 < x < π/2.
  7. Extend to −π/2 < x < 0 by evenness.
  8. Apply the Squeeze Theorem: lim cos x = lim 1/cos x = 1, so lim sin(x)/x = 1.

General template: to compute a hard limit, find simpler upper and lower bounds that hold near the point (but not at it) and have the same limit. Then squeeze.

Pitfalls & warnings

  • Do not divide by x and then claim the inequality holds at x = 0. It holds only for x near 0 with x ≠ 0, which is exactly what a limit needs.
  • When you manipulate inequalities, make sure you multiply or divide only by positive quantities. This is fine in the first quadrant; for negative x, use evenness or track the signs carefully.
  • The inequality must hold on a punctured neighbourhood (both sides of 0) before you can apply the squeeze.

Exam-ready checklist

  • Draw the unit-circle picture and identify the segments sin x, cos x and tan x.
  • Derive the sector-area formula ½xR² from proportionality to the angle.
  • Reproduce the chain of area inequalities and turn it into cos x ≤ sin x/x ≤ 1/cos x.
  • Justify the case of negative x using evenness.
  • State the Squeeze Theorem correctly and use it to conclude lim_{x→0} sin x / x = 1.

Big idea

There are three basic methods for computing lim_{x→a} f(x):

  1. If f is continuous at a, evaluate.
  2. Otherwise, manipulate f algebraically into a function that is continuous at a.
  3. Reduce the problem to a limit you already know.

Harder limits often combine several of these.

Notation & conventions

  • An algebraic manipulation only needs to be valid near a, not at a. For example, you may cancel or multiply by a factor that is 0 at a, as long as it is nonzero near a.
  • Getting "0/0" on direct substitution is a signal to simplify. It is not an answer.

Theorems / facts

  • If f is continuous at a, then lim_{x→a} f(x) = f(a).
  • lim_{x→0} sin(x)/x = 1 (proved in 2.18).
  • lim_{x→0} sin(ax)/(ax) = 1 for any constant a ≠ 0.
    • Reason: substitute u = ax. As x → 0, u → 0, so the limit is lim_{u→0} sin u / u = 1.
  • Identity used in the examples: 1 − cos²x = sin²x.
  • Other methods mentioned but not covered here:
    • the Squeeze Theorem (useful for some limits);
    • L'Hôpital's rule (needs derivatives);
    • Taylor series (the most powerful method, but needs power series).

Methods & proof templates

Method 1: Is the function defined and continuous at a? If so, evaluate.

  • Ex 1: lim_{x→2} (x sin x + eˣ)/√(x²+7). The function is continuous on its domain and 2 is in the domain, so the limit is (2 sin 2 + e²)/√11.

Method 2: Algebraic manipulation (turn the function into one that is continuous at a).

  • Factoring. Ex 2: lim_{x→2} (x²−4)/(x²−3x+2).
    • Substituting gives 0/0, so (x−2) is a factor of both the numerator and the denominator.
    • (x²−4)/(x²−3x+2) = (x−2)(x+2)/((x−2)(x−1)) = (x+2)/(x−1) for x ≠ 2.
    • Evaluate at 2: (2+2)/(2−1) = 4.
  • Conjugate. Ex 3: lim_{x→0} (1−√(1+x))/x.
    • Multiply the numerator and the denominator by 1+√(1+x).
    • The numerator becomes a difference of squares: 1−(1+x) = −x.
    • Divide by x to get −1/(1+√(1+x)). This is continuous at 0, so the limit is −1/2.

Method 3: Reduce to a problem you have already solved.

  • Ex 4: lim_{x→0} sin(2x)/x.
    • Multiply and divide by 2: sin(2x)/x = 2·sin(2x)/(2x).
    • The limit is 2·1 = 2.
  • Ex 5: lim_{x→0} sin(2x)/sin(3x).
    • Rewrite as (2x/3x)·(sin 2x/2x)·(3x/sin 3x).
    • The first factor equals 2/3 for x ≠ 0, and the other two factors each tend to 1.
    • Answer: 2/3.
  • Ex 6 (combining methods): lim_{x→0} (1−cos x)/x².
    • Multiply and divide by 1+cos x, a sort of conjugate.
    • The numerator becomes 1−cos²x = sin²x, so the expression is (sin x/x)²·1/(1+cos x).
    • The first factor tends to 1, and the second is continuous at 0, so evaluate it there.
    • Answer: 1·½ = 1/2.

Pitfalls & warnings

  • You cannot "evaluate" at a point where the function is undefined, as in the 0/0 cases.
  • Cancellations and multiplications must be by quantities that are nonzero near the point. Being zero at the point is fine.
  • You only know one trig limit, which involves sine. When cosine appears, use the conjugate trick or an identity to produce a sine.
  • Watching this summary is not enough; the lecturer stresses that you need to practise.

Exam-ready checklist

  • Check continuity first and evaluate directly when you can.
  • Recognise 0/0 and factor out the common factor (x − a).
  • Rationalise with a conjugate to remove square roots.
  • Rescale to use lim sin(ax)/(ax) = 1, including ratios such as sin(2x)/sin(3x) → 2/3.
  • Combine techniques, for example to get (1−cos x)/x² → 1/2.

Big idea

As x → ±∞, only the dominant (highest-power) term of each polynomial matters. You justify this rigorously by factoring out the largest power, so that every remaining term tends to 0. The same method works for some expressions involving roots.

Notation & conventions

  • The method is presented for x → ∞; the case x → −∞ works the same way.
  • A rational function is a quotient of polynomials.
  • You may guess the dominant term, but you must justify the answer by factoring. Do not just assert it.

Theorems / facts

  • The method rests on two basic limits:
    • lim_{x→∞} x = ∞
    • lim_{x→∞} 1/x = 0
  • Everything else follows from these two together with the limit laws. In particular, 1/xⁿ → 0 for n ≥ 1.
  • For a polynomial at ∞, only the term with the largest exponent determines the limit.
  • For a rational function at ∞, only the leading term of the numerator and the leading term of the denominator matter.
  • Inside a root, the largest power counts according to the root. For example, √(x⁴) = x², so √(x⁴+1) behaves like x².

Methods & proof templates

Template:

  1. Identify the largest power in the numerator and in the denominator. Inside a √, count √(xⁿ) as x^{n/2}.
  2. Factor that power out of each sum. For a root, first factor the power inside the root, then use √(ab) = √a·√b.
  3. Cancel the common powers.
  4. Every leftover term of the form c/xᵏ tends to 0. Apply the limit laws.

Ex 1: lim_{x→∞} (2x³ − 3x² + 7).

  • Factor out x³: x³(2 − 3/x + 7/x³).
  • The bracket tends to 2, so the expression behaves like 2x³ and the limit is ∞.

Ex 2: lim_{x→∞} (2x² + x − 1)/(3x² + 10x + e).

  • Factor x² from the top and the bottom: x²[2 + 1/x − 1/x²] / (x²[3 + 10/x + e/x²]).
  • Cancel x². The remaining small terms tend to 0, so the limit is 2/3.

Ex 3: lim_{x→∞} (√(x⁴+1) + x²)/(√(2x⁴+1) + 2x).

  • Guess the dominant terms: in the numerator, x² and √(x⁴) = x²; in the denominator, √(x⁴) = x² beats x.
  • Inside the roots: √(x⁴(1+1/x⁴)) = x²√(1+1/x⁴), and √(x⁴(2+1/x⁴)) = x²√(2+1/x⁴).
  • Factor out x² everywhere and cancel: (√(1+1/x⁴) + 1)/(√(2+1/x⁴) + 2/x).
  • The limit is (1+1)/√2 = √2.

Pitfalls & warnings

  • For a sum such as 2x³ − 3x², do not reason "∞ − ∞". Factor out the dominant power instead.
  • Be careful with square roots: x⁴ under a root contributes x², not x⁴.
  • Do not simply assert that "only the biggest term matters". Show the factorisation that justifies it.
  • (Implicit) For x → −∞ with roots, keep track of signs; √(x²) = |x|.

Exam-ready checklist

  • State the two base limits, x → ∞ and 1/x → 0, and explain how the limit laws build everything else from them.
  • Compute polynomial limits at ±∞ from the leading term, with justification.
  • Compute rational-function limits at ∞ by factoring out the highest power from the top and the bottom.
  • Handle expressions with roots by factoring inside the root first. For example, Ex 3 gives √2.

Big idea

The Extreme Value Theorem gives simple sufficient conditions for a function to have a maximum and a minimum: continuity on a closed, bounded interval [a,b]. It guarantees existence only; it does not tell you how to find the extrema.

Definitions

  • Maximum on a set: f has a maximum on a set I when ∃c ∈ I such that ∀x ∈ I, f(x) ≤ f(c).
    • The maximum is the output value f(c).
    • We say f has a maximum at c (the input).
  • Minimum on a set: f has a minimum on I when ∃c ∈ I such that ∀x ∈ I, f(x) ≥ f(c).
  • "The maximum of f" with no set specified means the maximum of f on its domain, the largest set on which f is defined.

Notation & conventions

  • Always say on which set. A function can have a maximum on one set and not on another.
  • The order of the quantifiers matters: ∃c ∀x. The single value c must work for every x. It is not enough for the inequality to hold for one particular x.
  • Keep "maximum" (a value of the output) separate from "at c" (a location in the input).

Theorems / facts

  • Extreme Value Theorem (EVT): If f is continuous on a closed, bounded interval [a,b] (both endpoints included), then f has a maximum and a minimum on [a,b].
    • That is, ∃c, d ∈ [a,b] such that ∀x ∈ [a,b], f(d) ≤ f(x) ≤ f(c).
  • The proof is long and technical. It belongs to a rigorous analysis course that constructs the reals axiomatically. In this course we accept EVT as an axiom.
  • Why each hypothesis matters (examples from the slides):
    • Continuous on [a,b] with the maximum at an interior point: has a max.
    • Continuous on [a,b] with the maximum at an endpoint: has a max. Endpoints are allowed.
    • Domain missing an endpoint, function bounded: no max. The function approaches a value at the missing endpoint but never reaches it. Bounded does not imply that a maximum exists.
    • Domain missing an endpoint, with a vertical asymptote: no max. The function is not even bounded.
    • Domain [a,b] but the function not continuous (a jump where the value at the top of the jump is an open circle): no max. So closedness of the interval alone is not enough.

Methods & proof templates

  • To guarantee extrema exist: check (1) that f is continuous and (2) that the set is a closed, bounded interval [a,b]. Then cite EVT.
  • To show EVT's conclusion can fail: break one hypothesis. Use an open or half-open interval, an unbounded function, or a discontinuity.
  • Challenge: construct f that is continuous on (0,1] with neither a maximum nor a minimum on (0,1]. The examples above, missing one endpoint, still had a minimum.
    • Hint from the lecture: sketch the graph first, then find a formula.
    • Possible answer (not given in the video): f(x) = sin(1/x), or (1/x)·sin(1/x), which oscillates with growing amplitude so that it is unbounded in both directions.

Pitfalls & warnings

  • EVT says nothing about how to compute the max or min; it gives existence only.
  • A bounded function need not attain a maximum.
  • Both endpoints must be included. Half-open intervals such as (0,1] can fail.
  • Continuity on the whole closed interval is required.
  • Do not drop the "on I" or mix up the order of the quantifiers in the definition.

Exam-ready checklist

  • Write the quantifier definitions of maximum and minimum on a set I.
  • Distinguish "the maximum is f(c)" from "f has a maximum at c", and know the default meaning (on the domain).
  • State EVT with all its hypotheses.
  • Give counterexamples showing that each hypothesis is needed (open endpoint, asymptote, discontinuity).
  • Construct a continuous function on (0,1] with no max and no min.

Big idea

A continuous function on [a,b] takes every value between f(a) and f(b). This lets us prove that an equation has a solution even when we cannot solve it, and locate the solution numerically by repeatedly halving the interval.

Definitions

  • (Bisection idea, informal.) If f is continuous and f changes sign on an interval, then a root lies in that interval. Evaluate f at the midpoint and keep the half on which f still changes sign.

Notation & conventions

  • c ∈ (a,b) means a < c < b, so c is strictly inside the interval.
  • "f takes the value M" means ∃c with f(c) = M.
  • Whenever you use the IVT, say that you are using a property of continuous functions, and check continuity.

Theorems / facts

  • Intermediate Value Theorem (IVT). Let f be defined on [a,b] and let M ∈ ℝ.
    • Hypotheses: f(a) < M < f(b) (or f(a) > M > f(b)), and f is continuous on [a,b].
    • Conclusion: ∃c ∈ (a,b) such that f(c) = M.
  • Equivalent form: if f is continuous on [a,b], then f takes all values between f(a) and f(b).
  • Special case (root finding): if f is continuous on [a,b] and f(a), f(b) have opposite signs, then ∃c ∈ (a,b) with f(c) = 0.
  • Why continuity matters: without it, the graph could jump over the value M (or over the axis) without ever taking it.
  • The IVT guarantees at least one c. The graph may cross the level many times.
  • Properties of the IVT, as listed in the lecture: easy to understand, easy to use, useful for proving other results, and difficult to prove. A rigorous proof belongs to an analysis course that defines the reals axiomatically, so it is not proved here.
  • Aside: x⁵ + 9x − 6 = 0 has no exact solution expressible with arithmetic operations and roots. There is no "quintic formula" in general; this is proved with Galois theory.

Methods & proof templates

Using the IVT to show an equation has a solution:

  1. Rewrite the equation as f(x) = 0, or as f(x) = M.
  2. State that f is continuous on [a,b]. For example, polynomials are continuous.
  3. Find a and b with f(a) < M < f(b) (or the reverse).
  4. Conclude by the IVT that ∃c ∈ (a,b) with f(c) = M.

Worked example: solve x⁵ + 9x − 6 = 0.

  • Let f(x) = x⁵ + 9x − 6. Then f(0) = −6 < 0 < 4 = f(1), and f is a continuous polynomial.
  • So ∃c ∈ (0,1) with f(c) = 0.
  • f(0.5) < 0, so the root lies in (0.5, 1).
  • Keep halving the interval. With enough patience this gives the root c ≈ 0.65343…

Bisection: it works, but it is a very inefficient numerical method. The lecturer does not recommend it in practice; he uses it here to show that you already believe the IVT.

Pitfalls & warnings

  • Do not forget to state and check continuity. The conclusion can fail without it.
  • The IVT gives existence, not uniqueness, and not a formula for c.
  • The values f(a) and f(b) must lie on opposite sides of M. Strict inequalities give c strictly inside (a,b).

Exam-ready checklist

  • State the IVT precisely, both the M-version and the "all values between f(a) and f(b)" version.
  • Prove that a given equation has a solution in a specific interval by choosing endpoints with opposite signs and citing continuity.
  • Narrow down the location of a root by bisection.
  • Explain why continuity is essential, with a jump-discontinuity counterexample.
