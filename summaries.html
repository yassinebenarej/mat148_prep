Formulas

  • A ⊆ B: every x ∈ A is in B; A ∪ B: in at least one; A ∩ B: in both
  • ℕ = {0,1,2,…} ⊆ ℤ ⊆ ℚ ⊆ ℝ

Know

  • ∈ / ∉: x ∈ A means x is an element of A.
  • ∅: the set with no elements.
  • ℕ: this course starts at 0; some books start at 1.
  • ⊆ vs ⊊: use ⊆ (may be equal) and ⊊ (strict); ⊂ is ambiguous.

Traps

  • ∈ relates element to set; ⊆ relates two sets.
  • Whether 0 ∈ ℕ is a convention; check it.

Formulas

  • Filter: {x ∈ source : constraint}
  • Image: {shape : x ∈ source}, e.g. {2x : x ∈ A}
  • [a,b] = {x ∈ ℝ : a ≤ x ≤ b}; (a,b) = {x ∈ ℝ : a < x < b}

Know

  • ":" or "|": read "such that"; only inside set-builder notation.
  • Brackets: square includes the endpoint, round excludes it.
  • ∞: not a number, so always a round bracket.

Steps

  1. Identify the source set (left).
  2. Apply the constraint (right).
  3. List the result if possible.

Traps

  • Never write [a, ∞].
  • Don't use ":" or "|" for "such that" elsewhere.

Formulas

  • ∀x ∈ A, P(x): every element of A satisfies P
  • ∃x ∈ A s.t. P(x): at least one element satisfies P

Know

  • "There exists": means at least one, never exactly one.
  • Free variable: "x² = 5" alone is a predicate, neither true nor false.

Steps

  1. Prove ∀: show it for every element.
  2. Disprove ∀: give one counterexample.
  3. Prove ∃: exhibit one example.
  4. Disprove ∃: show no element works.

Traps

  • Never start a definition or proof with an unquantified formula.

Formulas

  • ∀x ∈ ℤ ∃y ∈ ℤ, x < y TRUE (y = x + 1)
  • ∃y ∈ ℤ ∀x ∈ ℤ, x < y FALSE

Know

  • ∀x ∃y: y may depend on x.
  • ∃y ∀x: y is chosen first, same for all x.

Steps

  1. Read left to right.
  2. For each ∃, ask: may it depend on earlier variables?

Traps

  • Swapping ∀ and ∃ usually changes the meaning (crucial in ε–δ, where δ depends on ε).

Formulas

  • ¬(∀x ∈ ℤ, x > 0) ⟺ ∃x ∈ ℤ s.t. x ≤ 0

Know

  • "Let x ∈ A": fix an arbitrary x; the proof must work for every x.
  • Disprove S: prove its negation ¬S.
  • ■ / □: marks the end of a proof.

Steps

  1. ∀x ∃y: fix an arbitrary x ("Let x ∈ A").
  2. Choose y in terms of x ("Take y = x + 1").
  3. Verify y is in the set and satisfies the condition.

Traps

  • "Take y = x + 1" is meaningless before "Let x".
  • Keep the order: fix, choose, verify.

Formulas

  • ∀x ∈ ∅, (anything) TRUE
  • ∃x ∈ ∅ s.t. (anything) FALSE

Know

  • Why ∀ is true: nothing to check, and no counterexample exists.
  • Why ∃ is false: there is no element to exhibit.

Traps

  • Don't call it "true only because I can't disprove it"; it is provable (nothing to check).

Formulas

  • P ⇒ Q ⟺ ¬Q ⇒ ¬P (contrapositive)
  • P ⇔ Q means (P ⇒ Q) and (Q ⇒ P)

Know

  • P ⇐ Q: means Q ⇒ P.
  • False hypothesis: P ⇒ Q is vacuously true.
  • iff: written "iff", spoken "if and only if".

Steps

  1. Prove P ⇒ Q: assume P, deduce Q.
  2. Or assume ¬Q, deduce ¬P.
  3. Prove P ⇔ Q: prove both directions.

Traps

  • P ⇒ Q does not give ¬P ⇒ ¬Q.
  • P ⇒ Q does not give Q ⇒ P.

Formulas

  • ¬(P ⇒ Q) ⟺ (P ∧ ¬Q)
  • ¬[∀x (P(x) ⇒ Q(x))] ⟺ ∃x (P(x) ∧ ¬Q(x))

Know

  • Hidden ∀: "If x ∈ A then x > 0" means ∀x ∈ ℝ, (x ∈ A ⇒ x > 0).
  • Forbidden case: only (P and ¬Q) is ruled out.

Steps

  1. Write out the hidden ∀.
  2. Change ∀ to ∃.
  3. Replace the implication with "P(x) and not Q(x)".

Traps

  • Never write the negation as an if-then.
  • The negation of x > 0 is x ≤ 0, not x < 0.

Formulas

  • x, y ≥ 0 ⇒ √(xy) ≤ (x+y)/2
  • √(a²) = |a|

Know

  • Rough work: manipulating the claim to find an idea; not a proof.
  • Theorem: must state its hypotheses ("Let x, y ≥ 0. Then…").

Steps

  1. Start from 0 ≤ (x−y)².
  2. Add 4xy, divide by 4: xy ≤ ((x+y)/2)².
  3. Take square roots (both sides ≥ 0).
  4. Use x, y ≥ 0 to drop the absolute value.

Traps

  • Forward from the claim to something true proves nothing.
  • Unused hypothesis means something is wrong.
  • √(a²) ≠ a in general.

Formulas

  • f increasing on I ⟺ ∀x₁, x₂ ∈ I, x₁ < x₂ ⇒ f(x₁) < f(x₂)

Know

  • Increasing on I: depends on the interval I, not just f.
  • Every symbol: must be introduced (f, I, where x₁, x₂ live).

Traps

  • f′ > 0 is not the definition; a corner function is increasing.
  • "and" instead of "⇒" changes the meaning completely.
  • Missing quantifier or missing interval makes the statement meaningless.

Formulas

  • ∀x₁, x₂ ∈ I, x₁ < x₂ ⇒ f(x₁) < f(x₂)

Know

  • WTS: "want to show"; labels your goal.
  • Let x ∈ S: fixes an arbitrary element.

Steps

  1. WTS: ∀x ∈ S, P(x) ⇒ Q(x).
  2. Let x ∈ S.
  3. Assume P(x).
  4. Argue; conclude Q(x). ∎

Traps

  • Don't write the goal as if already known.
  • Don't pick specific numbers for a "for all" claim.
  • Never assume the conclusion.

Formulas

  • g not increasing on I ⟺ ∃x₁, x₂ ∈ I, x₁ < x₂ and g(x₁) ≥ g(x₂)
  • ¬(P ⇒ Q) = P ∧ ¬Q; ¬∀ = ∃¬

Steps

  1. Negate the definition.
  2. Name specific witnesses (sketch the graph).
  3. Check they lie in I.
  4. Verify every condition. ∎

Traps

  • ¬(a < b) is a ≥ b, not a > b.
  • Negation of an implication is "and", not an implication.
  • For ∃ choose values; don't fix arbitrary ones.

Formulas

  • f, g increasing on I, h = f+g ⇒ h increasing on I

Know

  • Hypothesis (IF): you may assume and use it.
  • Conclusion (THEN): what you must prove.

Steps

  1. WTS ∀x₁, x₂ ∈ I, x₁ < x₂ ⇒ h(x₁) < h(x₂).
  2. Let x₁, x₂ ∈ I; assume x₁ < x₂.
  3. Apply hypotheses: f(x₁) < f(x₂), g(x₁) < g(x₂).
  4. Add the inequalities. ∎

Traps

  • Unlabelled goal looks like assuming the conclusion.
  • Never prove the hypothesis; never assume the conclusion.

Formulas

  • Base: S_{n₀}; Step: ∀n ≥ n₀, Sₙ ⇒ Sₙ₊₁
  • (n+1)! = (n+1)·n!; 2ⁿ⁺¹ = 2·2ⁿ

Know

  • Induction hypothesis: the assumption Sₙ inside the step.
  • Example: n! > 2ⁿ for all n ≥ 4.

Steps

  1. State "by induction on n".
  2. Base case: check n = n₀.
  3. Let n ≥ n₀; assume Sₙ; WTS Sₙ₊₁.
  4. Rewrite n+1 case via n; cite hypothesis. ∎

Traps

  • The step proves only an implication, not Sₙ₊₁.
  • Base case is the smallest n in the claim.
  • Fix n before assuming anything.

Formulas

  • ∀n ≥ 1, 1+2+…+n = n(n+1)/2

Steps

  1. Direct: write Sₙ forwards and reversed.
  2. Add: n pairs each summing n+1, so 2Sₙ = n(n+1).
  3. Induction base: n = 1 gives 1 = 1·2/2.
  4. Step: split off last term, apply hypothesis.
  5. Simplify to (n+1)(n+2)/2. ∎

Traps

  • WTS for n+1 is (n+1)(n+2)/2, not n(n+1)/2 + 1.
  • Don't assume induction is the only option.

Formulas

  • lim_{x→a} f(x) = L: x very close to a, x ≠ a ⇒ f(x) very close to L

Know

  • Hole: f undefined at a, but the graph can be a nice curve minus one point.
  • Cancelling: f = g except at a, so lim f = g(a) if g is nice.

Steps

  1. Factor, or multiply by the conjugate, to remove 0/0.
  2. Cancel, noting "valid only for x ≠ a".
  3. Plug a into the simplified g.

Traps

  • Cancelled function is a different function; name it g.
  • A table of values only suggests the limit.

Formulas

  • lim_{x→a} f(x) = ∞: x close to a, x ≠ a ⇒ f(x) arbitrarily large

Know

  • DNE: f(x) does not approach one single number.
  • "= ∞": the limit does NOT exist, and it fails by growing unbounded.
  • Oscillation: sin(π/(2x)) takes values 1, 0, −1 near 0, so DNE.

Traps

  • ∞ is not a number; "= ∞" does not mean the limit exists.
  • Sampling only one subsequence can hide oscillation.

Formulas

  • x→a⁺: x close to a, x > a (from the right)
  • x→a⁻: x close to a, x < a (from the left)

Know

  • DNE ways: ∞, −∞, different side limits, oscillation.
  • f(a): undefined or not, it does not affect the limit.

Steps

  1. Split |x| into cases: x if x > 0, −x if x < 0.
  2. Simplify each side and take its side limit.
  3. Compare the two side limits.

Traps

  • Mixing up + (right, x > a) and − (left).
  • Saying only "DNE" without saying how it fails.

Formulas

  • lim_{x→a} f(x) = L ⇔ ∀ε>0 ∃δ>0 (∀x) 0<|x−a|<δ ⇒ |f(x)−L|<ε
  • lim_{x→a} f(x) = ∞ ⇔ ∀M ∃δ>0: 0<|x−a|<δ ⇒ f(x)>M

Know

  • 0 < |x−a|: excludes x = a, so f(a) plays no role.
  • Picture: inside the δ-strip, the graph stays inside the ε-band.
  • Smaller ε: makes the condition harder; a smaller δ makes it easier.

Traps

  • Order matters: ∀ε ∃δ, not ∃δ ∀ε.
  • Dropping "0 <" or changing strictness changes the meaning.

Formulas

  • lim_{x→∞} f(x) = L ⇔ ∀ε>0 ∃M∈ℝ: x>M ⇒ |f(x)−L|<ε

Know

  • Horizontal asymptote: the line y = L when lim_{x→∞} f(x) = L.
  • M: depends on ε; smaller ε usually needs bigger M.
  • Domain: f must be defined on some (p, ∞).

Traps

  • A graph may touch or cross its asymptote, even infinitely often.
  • One fixed (ε, M) pair is not enough.

Formulas

  • lim_{x→3} (2x+1) = 7: |(2x+1)−7| = 2|x−3| < 2δ = ε, δ = ε/2

Steps

  1. Let ε > 0 (arbitrary, no restrictions).
  2. Take δ = (function of ε) from rough work.
  3. Let x ∈ ℝ; assume 0 < |x−a| < δ.
  4. Chain inequalities to conclude |f(x)−L| < ε.

Traps

  • Choosing δ before fixing ε gives a pseudo-proof.
  • Rough work is not the proof; write it in logical order.
  • Any smaller positive δ also works.

Formulas

  • lim_{x→4} (x²+1) = 17: |x²−16| = |x+4||x−4|
  • δ ≤ 1 ⇒ 3<x<5 ⇒ |x+4|<9; take δ = min{1, ε/9}

Steps

  1. Factor |f(x)−L| = |x−a|·(extra factor).
  2. Cap δ ≤ 1 to bound the factor by C.
  3. Set δ = min{1, ε/C}; state both consequences.
  4. Prove in order: ε, δ, x, then inequalities.

Traps

  • δ = ε/|x+4| is wrong; δ cannot depend on x.
  • Establish each bound on x before using it.

Formulas

  • lim h = L ⇔ ∀ε>0 ∃M ∀x>M: |h(x)−L|<ε
  • lim h DNE ⇔ ∀L ∃ε>0 ∀M ∃x: x>M and |h(x)−L|≥ε

Know

  • Negation: ∀↔∃, and ¬(P⇒Q) is "P and not Q".
  • Hidden ∀x: the implication hides a ∀x, which becomes ∃x.

Steps

  1. Let L be arbitrary.
  2. Take ε (may depend on L).
  3. Let M be arbitrary.
  4. Take x > M (may depend on L, M).
  5. Verify |h(x)−L| ≥ ε.

Traps

  • "≠ L" is not DNE; you need ∀L.
  • Negation of "< ε" is "≥ ε".
  • Choosing ε too large makes the proof impossible.

Formulas

  • |A+B| ≤ |A|+|B|
  • |f(x)+g(x)−(L+M)| ≤ |f(x)−L| + |g(x)−M| < ε/2+ε/2

Know

  • Goal limit: ε is given; you must build δ.
  • Hypothesis limit: you choose ε (here ε/2); δ is guaranteed.

Steps

  1. Let ε > 0.
  2. Use ε/2 on f to get δ₁.
  3. Use ε/2 on g to get δ₂.
  4. Take δ = min{δ₁, δ₂}.
  5. Assume 0<|x−a|<δ; apply triangle inequality.

Traps

  • Fix ε before using ε/2.
  • Hypotheses give different δs; name them δ₁, δ₂.
  • Rough work is not the proof; write in logical order.

Formulas

  • h ≤ g ≤ f near a (x≠a), lim f = lim h = L ⇒ lim g = L
  • −x² ≤ x² sin(1/x) ≤ x² ⇒ lim_{x→0} x² sin(1/x) = 0

Know

  • Condition: inequalities only need to hold near a, not at a.
  • lim sin(1/x) at 0: DNE (oscillates between −1 and 1).

Steps

  1. Bound the bad factor (−1 ≤ sin ≤ 1).
  2. Multiply by the good factor, watching signs.
  3. Show both bounds tend to the same L.
  4. Cite "By the Squeeze Theorem".

Traps

  • Product law with lim sin(1/x) is invalid, even if the answer is 0.
  • Bounds with different limits give no conclusion.

Formulas

  • ∃p>0: 0<|x−a|<p ⇒ h(x) ≤ g(x) ≤ f(x)
  • L−ε < h(x) ≤ g(x) ≤ f(x) < L+ε

Know

  • Goal limit: fix arbitrary ε, find δ.
  • Hypothesis limit: choose ε, get δ₁ or δ₂.
  • |g−L|<ε: equivalent to L−ε < g < L+ε.

Steps

  1. Let ε > 0.
  2. Use ε on lim f: get δ₁, so f < L+ε.
  3. Use ε on lim h: get δ₂, so h > L−ε.
  4. Take δ = min{δ₁, δ₂, p}.
  5. Assume 0<|x−a|<δ and chain the inequalities.

Traps

  • Forgetting p in the minimum.
  • Treating hypotheses like goals (fixing ε instead of choosing it).

Formulas

  • continuous at a ⇔ lim_{x→a} f(x) = f(a)
  • ∀ε>0 ∃δ>0 ∀x: |x−a|<δ ⇒ |f(x)−f(a)|<ε
  • on [a,b]: lim_{x→a⁺} f = f(a), lim_{x→b⁻} f = f(b), continuous on (a,b)

Know

  • Three conditions: limit exists, f(a) defined, they are equal.
  • "0<" dropped: at x = a, |f(a)−f(a)| = 0 < ε automatically.
  • "f is continuous": means continuous on its domain.
  • Closed interval: one-sided limits at endpoints only.

Traps

  • Hole with f(a) undefined or "wrong" is a discontinuity.
  • Continuous on domain can still fail at a point outside the domain.

Formulas

  • basic: c, x, eˣ, ln x, sin x, |x|
  • cos x = sin(π/2−x), tan x = sin x/cos x, √x = e^{(1/2)ln x}
  • f,g continuous at a ⇒ f+g, fg, f/g (g(a)≠0) continuous at a

  • Main theorem: sums, products, quotients, compositions of basic functions are continuous on domain.
  • Sum proof: limit law gives lim(f+g) = f(a)+g(a) = (f+g)(a).
  • Composition: no limit law; needs separate argument (2.16).

  • Plugging in fails if the point is outside the domain (sin x / x at 0).
  • tan x is not continuous at π/2.

Formulas

  • Removable: lim_{x→a} f(x) exists and ≠ f(a) (or f(a) undefined)
  • Fix: F(x)=f(x) for x≠a, F(a)=lim f

Know

  • Non-removable: limit does not exist (jump, vertical asymptote, oscillation).
  • Removable: appears as a hole on the graph.

Steps

  1. Check whether lim f exists.
  2. If not: non-removable.
  3. If yes, compare with f(a): equal means continuous, else removable.

Traps

  • A defined f(a) does not imply continuity.
  • f and its fixed version are different functions.

  • Sector area = ½·x·R²

Formulas

  • lim_{x→0} sin(ax)/(ax) = 1 (a≠0)
  • 1 − cos²x = sin²x

Steps

  1. Continuous at a? Substitute.
  2. 0/0: factor out (x−a) and cancel.
  3. Square roots: multiply by the conjugate.
  4. Rescale to sin(ax)/(ax), e.g. sin2x/sin3x → 2/3.
  5. For (1−cos x)/x²: multiply by 1+cos x, giving ½.

Traps

  • 0/0 is a signal to simplify, not an answer.
  • Cancelled factors must be nonzero near a, not at a.

Formulas

  • lim_{x→∞} x = ∞, lim_{x→∞} 1/x = 0
  • √(x⁴) = x²

Steps

  1. Find the largest power top and bottom (√xⁿ counts as x^{n/2}).
  2. Factor it out of each sum.
  3. Cancel common powers.
